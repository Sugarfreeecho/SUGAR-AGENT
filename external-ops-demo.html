权限与安全 Security & Permissions
工作区外处理权限
授权入口在审批卡片：当写、删除或 Shell 触发工作区外操作时，选择“授权工作区沙箱外处理权限”即可一次性放开；此处仅提供撤销。
正在读取状态…
该权限不覆盖：工作区外读取（read_file / ls / glob / grep）、网络（web_fetch / curl / git push）、 动态代码（python -c）、破坏性命令（rm -rf）、凭据导出与安全策略篡改——这些仍按原规则逐次审批或直接拒绝。
撤销工作区外处理权限？
撤销后，写、删除和 Shell 在工作区外的操作将恢复逐次审批。
