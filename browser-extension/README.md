# SugarAgent 浏览器扩展

侧栏与主程序共享会话，并通过 Playwright MCP 使用当前浏览器登录态完成网页任务。安装的是一个 SugarAgent 扩展；不需要再安装官方 Playwright 扩展，也不需要用调试参数重启日常浏览器。

0.6.36 为持续延迟问题增加可核对的同步诊断，不宣称已修复该现象的根因。设置页「复制同步诊断」可导出扩展后台接收、侧栏接收、过滤、去重/应用、提交与自动补载触发记录，按会话/运行/执行编号关联，区分实时、缓存和快照。记录有界，仅包含时间和身份状态，不包含正文、工具命令、附件或凭据。0.6.35 的补载仍是恢复兜底，补现不等于实时链路已恢复。重新加载扩展即可使用诊断，无需重启后端。

0.6.35 补齐运行中断更恢复：侧栏约 12 秒未收到内容进度时检查正式事件游标；后端仍在运行且记录已前进，自动重订阅并补载历史和执行快照。心跳、Token 用量及指标不会掩盖正文漏传，长工具静默且游标未变时不会反复重连。即使整次外部启动都漏收、侧栏仍以为空闲，也会恢复。补载保留草稿、Pending、已加载历史范围及阅读跟随状态，不重发消息或执行工具。重新加载扩展即可，无需重启正在运行的后端。

0.6.34 补齐会话失败与中断提示：识别后端 `error` 字段及结构化模型错误；紧凑提示始终显示在执行过程折叠区外，详情可展开。主界面停止会同步到侧栏；运行中定期核对后端状态，漏收结束事件时从历史恢复，无法确认结果则明确提示，避免一直显示正在执行。重新加载扩展即可生效，无需重启后端。

0.6.33 修复刚打开会话后，图片延迟加载使底部定位丢失的问题。缓存回放不再提前切换到流式滚动；图片撑高内容产生的布局滚动不再被误判成用户上翻。历史图片分批加载时保持直接置底，用户主动上翻则保留阅读位置，新生成仍沿用平滑滚动。重新加载扩展即可生效。

0.6.32 修复跨轮消息连续性：旧运行的迟到结束事件不再关掉新运行；缺少用户消息的历史页也可接上新的 Pending 执行组；工具数组下标不再用于全局去重。重连恢复工具、未完成思考与正文，并用流式游标拒绝旧片段；迟到快照不覆盖终稿。订阅队列溢出、转发或发送任务异常时关闭连接并自动补历史，避免显示已连接却不再出字。需要重启后端并重新加载扩展。

0.6.31 隔离主／子会话：子 Agent 转发的正文、思考、工具、提问及结束事件不再进入主会话。标题栏新增紧凑的「子 Agent」胶囊，可按层级切换主／子会话，子会话旁可一键返回父会话；独立保存草稿、附件和 Skill，重开侧栏恢复当前子会话。目录标注运行中及待处理状态，没有独立会话的汇总任务只显示记录。需要重启后端并重新加载扩展。

0.6.30 按侧栏的紧凑原则调整 Pending 与交互卡：每个待发任务一条 30px 单行，保留编辑、方式选择、立即插话和撤回，附件只显示小标记；移除独立大标题与重复状态行。提问／审批、文件预览和弹窗标题清除页面级内边距。修复主 UI Pending 在同一个 run 内自动续发时，后续用户消息被当作上一轮正文、回答被旧完成状态拦截的问题；用户消息、回答、过程及交互卡按真实消息边界隔离，历史、刷新和补载沿用同一规则。重新加载扩展即可生效。

0.6.29 压缩工具展开内容的空白：参数、实时输出、结果不再继承页面 section 的 16px 内边距；纯文本块去掉叠加的 8px 内边距，分区间距缩到 6px。命令、参数与输出的原始缩进和换行保留，Markdown 代码块继续使用自己的样式。重新加载扩展即可生效。

0.6.28 修复审查发现的三处问题：会话切换失败时丢弃目标会话的缓冲并恢复原订阅；用户气泡补取合并在途请求，历史暂未命中时退避重试，不再两次后永久放弃；思考开始与结束时间写入正式执行日志，新进程直接恢复，旧版没有测量起点的记录仍留空。需要重启后端并重新加载扩展。

0.6.27 修复后端重启后，同一条用户消息的执行过程显示为两个总开关的问题。沿用后端持久的执行组标识，重启前后的思考和工具共享展开／收起、总计数和完成状态；原始运行及工具身份分别保留。独立的新消息仍有自己的执行过程，正文和插话不受折叠影响。已有历史、实时恢复和重新加载均适用。本次只需重新加载扩展。

0.6.26 补齐 Pending 与 Steer interrupt。与主 UI 一致：生成中第一次 Enter（或点击发送）把消息放入 Pending；输入清空后再按 Enter，优先把刚排入的那条以 Append 插话发送。每条待发消息可选择 Append／Interrupt、立即插话、原位编辑和撤回；未手动发送的条目等本轮结束后按顺序执行。文字、图片、文件、网页资料和 Skill 保留，刷新可恢复队列，编辑不覆盖当前输入草稿。Interrupt 复用后端真实中断及续接流程，不可中断的操作仍等待安全边界。此版本需重启后端并重新加载扩展。

0.6.25 思考条目测不到用时时不再显示“—”，直接留空；工具条目仍保留“—”。当时的开始时间只写入内存运行状态，跨进程恢复未接通；0.6.28 改为正式执行日志持久化。

0.6.23 修复主程序发送的消息偶尔在侧栏只看到生成过程、没有用户气泡的问题：会话重载时保留刚启动而历史快照尚未包含的实时轮次，补齐快照里缺失的用户消息，重载结束后再补放期间缓冲的事件；仍未取到时按本轮 run 从历史补取一次。本次只需重新加载扩展。

0.6.16 修复扩展管理页和工具栏回退为默认图标的问题：品牌图改为真正的 PNG 编码并声明对应尺寸。已在 Edge 管理页验证品牌图标，并连续两次点击“重新加载”验证配对保留。

生成中有内容时先进入 Pending；输入为空再按 Enter，发送最近排入的待发项（没有最近项时选择第一条）。默认 `Steer append`，条目菜单可改为 `Steer interrupt`。插话先显示“待采纳”，实际消费后显示“已采纳”；折叠执行过程不隐藏插话气泡和图片。输入为空时主按钮仍用于停止，Enter 不停止任务；停止保留草稿。Shift+Enter／Ctrl+Enter 换行。转换插话时提交失败会保存原内容，刷新后可继续重试，使用固定准入键避免重发同一条。

0.6.15 修复插件停用、重新加载或后端断线后反复要求配对的问题。长期配对不再使用插件运行批次的有效期；暂时不可用时保留会话和草稿，自动重连。只有确认授权被撤销或到期才显示重新配对。

更新时先在扩展管理页重新加载扩展，再重启开发后端。仍保存在浏览器内的旧配对会自动恢复；如果旧版已清掉本机凭据，更新后需要再配对一次。

## 桌面安装包

正式打包会自动构建本扩展，并将 `dist` 和 ZIP 连同浏览器连接后端、独立 Node 及 Playwright 生产依赖放入主程序安装包。用户在主程序设置中启用浏览器连接，按向导加载扩展并配对，无需安装 Node/npm。下方开发环境步骤仅用于源码构建。

## 环境与构建

- 本机 SugarAgent 仓库及其 Python 后端。
- Node.js 22.18+（当前验证使用 Node.js 24）。
- Chrome／Edge 125+；浏览器策略可能限制调试接口。

在仓库根目录依次执行：

```powershell
cd plugins/browser-use/node
npm ci
cd ../../../browser-extension
npm ci
npm run build
```

运行时复用已安装的浏览器。验证时下载的 Chrome for Testing 仅供测试，不会被扩展或运行时作为日常浏览器启动。

## 加载与配对

在主程序 **设置 → 浏览器连接** 中跟随安装向导完成，插件未启用时也能进入此页：

1. **准备服务**：启用插件、检测运行组件，缺少组件时点击安装。首次更新后端代码，可使用页面里的重启入口；页面会展示实际运行影响并请求本次确认。不支持页面重启的启动方式会提示使用托盘或开发终端。
2. **加载扩展**：选择 Chrome 或 Edge，复制扩展管理页地址。直接打开扩展文件夹，或下载 ZIP 并解压；在管理页开启开发者模式，加载 `dist` 或解压目录，再固定工具栏图标。
3. **完成配对**：为浏览器命名，在页面复制服务地址、生成一次性配对码。点击 SugarAgent 图标打开侧栏，输入并连接。向导会自动检测配对结果和在线状态，配对码十分钟后过期。
4. **开始使用**：从页面复制示例任务，或打开主程序。页面下方可查看连接、设置默认浏览器和撤销配对；撤销前会确认。

没有自动重启正在运行的后端，也没有自动更改浏览器的开发者设置。页面不会假装能直接打开浏览器内部地址；提供复制地址与实际加载步骤。

固定扩展 ID：`mdiicfkdpohkiccgjiomnlmokamaafbo`。Chrome 和 Edge 均使用对应的 `chrome-extension://` 来源。不要替换清单中的公钥；它不包含私钥。

只支持本机地址。配对不需要开启旧远控功能，也不需要修改 `.env` 或全局 CORS。

## 使用

- 0.6.8 使用已确认的 M 组合：紧凑会话顶栏、12px 正文、最近会话起始页与平直输入面板。默认深色，顶栏菜单或设置中可切换浅色、深色或紫色。
- 侧栏设置页显示当前已加载扩展的版本；主程序浏览器连接设置页显示本机扩展包版本，均从实际 manifest 读取。
- 主程序中的“浏览器连接”使用原生设置页签，沿用主设置的控件、卡片、主题和字号；分步安装、配对和浏览器管理在同一分区中完成，停用插件时仍可进入设置启用。独立页面入口继续可用。
- 默认自动关联发送时活动页的标题、网址、稳定标签标识及选区。直接输入“总结这页”或选中文字后输入“解释这段”即可，Agent 按需读取页面，不必先手动附加。侧栏设置中的“自动关联当前网页”可关闭此行为；暂停浏览器控制时也不自动采集。
- 本轮任务绑定发送时的页面，排队或执行期间手动切换标签不会改目标。Agent 明确选择或新建标签时可以改变目标；原绑定页被关闭时会报出原因，要求重新选择。
- 主程序 Agent 可调用只读 `browser_get_context` 查询当前活动页、本轮绑定页和选区。页面正文与截图仍使用既有 Playwright 工具按需获取。
- 点击顶部会话名打开搜索菜单，选择已有会话；菜单底部可进入完整管理页。右侧新建按钮创建新会话，更多菜单可打开设置与主程序。
- 会话菜单每行显示相对时间和三点操作，可改名、置顶、归档或确认删除；时间提示展示完整时间。
- 主程序改名或回复完成后自动命名，会实时更新侧栏标题及会话菜单；侧栏订阅跨多轮保留，不会在第一轮结束后停止接收消息。
- 侧栏可见并聚焦、且所属浏览器窗口在前台时，与主界面一样抑制系统通知。切到网页、其他应用或关闭侧栏后恢复正常通知判断；重连会重新检测焦点，异常断开也会清理短期焦点租约。
- 输入区上沿选择工作区，可从最近目录、系统目录选择器或手动绝对路径中选择；已有会话的变更会保存并读回确认。
- 上沿“文件”上传附件；右侧显示上下文使用百分比，展开可查看实际 tokens、容量和组成。用量与主程序口径一致，接收实时事件更新；不可用时显示“—”。
- 输入框支持直接粘贴截图、图片及多个文件，复用已有上传和消息附件流程；图片与文字混合粘贴时，文字插入当前光标处。普通文字粘贴保持浏览器默认行为。上传期间禁止提前发送；失败保留草稿，可重新粘贴，切换会话不会把附件加到另一条会话。
- 加号右侧是权限选择器，窄侧栏只显示盾牌图标。请求批准／替我审批／完全访问沿用主程序设置，对所有会话生效；开启完全访问需要在界面再次确认。
- 权限入口使用主程序相同的三种盾牌图标和各主题的绿／蓝／橙色。主程序修改权限后实时同步，较慢的旧请求不会覆盖新状态。
- 输入区右下角选择模型与思考强度。尚未建立会话时只暂存选择，首次发送时使用这些设置。
- `ask_user` 显示可操作的提问卡：支持单选、多选、其他答案、选项预览、参考图片、逐题跳过、回答确认和取消。草稿可在侧栏关闭或刷新后恢复；失败不会清空答案。提交后等待中的 Agent 继续执行。
- 审批卡支持风险分析、本次允许、任务内或长期规则授权、工作区外处理授权，以及带原因拒绝。可用范围由后端控制，危险审批只允许本次确认；处理后显示只读结果，主程序处理的结果也会同步。
- 思考强度使用 `low`、`medium`、`high` 等原始名称。思考框流式跟随底部，向上阅读时暂停跟随；思考结束后自动折叠，任务成功后折叠执行过程。
- 思考和工具条目显示实时用时，完成后冻结；工具优先采用后端实际执行耗时，新采集的思考计时会随历史保存。思考没有测到用时（例如通道没有给出流式思考增量）时留空，工具没有记录时仍显示“—”。工具状态统一按界面语言显示；条目展开箭头与总开关使用同一 SVG，围绕中心旋转。
- 工具标题行在名称后显示本次调用的命令（其他工具为参数摘要），与名称同字号同基线，单行省略且不会挤掉名称，悬停可看全文；展开后显示生成的参数、实时输出与结果，执行时持续追加实际 stdout／stderr。内容跟随底部，向上阅读时暂停跟随。完成后自动折叠，重新打开可查看参数与结果；刷新／重连后恢复输出并继续追加，避免重复。没有提供增量输出的工具显示真实最终结果。
- 正文、思考和工具输出复用主 UI 的逐帧平滑滚动；连续输出和异步内容高度变化保持缓动，上翻或选中文字会暂停跟随，点击“新内容”恢复。切换会话和加载更早消息会清理旧动画并保留正确位置；尊重系统减少动态效果设置。
- 刚打开、重开或切换会话时，历史内容直接置底，稍后加载的历史图片等也不会触发入场滚动动画。后续新生成内容继续平滑跟随。
- 条目箭头为 12px，总展开箭头保留 14px。
- 发送／停止合用右下角同一个按钮，运行中显示停止并保留正在编辑的草稿；空闲后恢复发送。点击发送立即显示用户气泡及发送／等待状态；服务端事件到达后合并，发送失败保留草稿。菜单可按 Escape 关闭，方向键导航；目录和改名验证失败保留输入。
- 点击加号附加当前网页或选择其他标签页；网页右键菜单也可附加正文或选区。
- 加号中的“选择 Skill”读取主程序相同的 Skill 列表，支持搜索、多选及移除，停用项不可新增选择。选择按会话保存草稿，随下一条消息提交，成功后清空；失败保留，支持只发送所选 Skill。后端重新校验可用状态，并复用主程序的显式 Skill 指令和消息展示，不改变全局启用状态。
- 附加内容是发送时的外部资料快照。切换标签不会自动上传网页，也不会切换会话。
- 手动附加保留用于固定某一时刻的网页正文；自动关联仅携带轻量页面引用及选区。
- 普通网页标签对 Playwright 可见；浏览器内部页面、扩展页面和隐私窗口不参与发现。
- 不同会话保留各自的当前标签，同一标签的修改权在任务结束后释放。
- 关闭侧栏不会停止任务。浏览器和本机后端需要保持运行；重连不会重放结果未知的点击或提交。
- “暂停控制”阻止新的网页操作；“停止任务”取消对应会话的执行。
- 临时思考状态只保留当前一条，输出或结束后清除；各阶段正文始终平铺，折叠执行过程不会隐藏正文。
- 工具提前执行时，同一推理轮次的流式正文与完整正文合并到同一段，保持在该轮工具之前；旧轮次的工具更新不会打断下一轮正文。不同轮次中相同的文本仍各自保留，历史重载沿用相同规则。
- Markdown 的表格、代码、数学和图示继续支持。工作区文件或会话附件链接可预览／下载，`.md` 在侧栏渲染，支持文档中的相对路径图片；普通外链在新标签打开。文件读取上限 2 MB。
- 本地 Markdown 链接兼容转义左括号、包含空格／中文／成对括号的 Windows 路径和 `file:///` 引用。文件夹链接可查看子项与上一级，文件可预览和下载；图片与图片文件链接可点击放大。代码块中的示例保持原样。目录读取沿用工作区及会话权限，每次最多显示 200 项。
- 远程图片直接由扩展无凭据读取，本机图片沿用认证接口；图片读取失败显示具体原因。
- 图片复用主程序的附件入库与读取；未发送的网页资料和文件保存在当前浏览器会话中，文字草稿保存在本机。
- 消息气泡下的用户图片按主界面附件卡呈现：缩略图、名称（未知时显示“图片”）与体积／格式，点击进入侧栏内预览；体积和格式优先取附件元数据，缺失时按实际读取结果补齐。
- 主程序发送的消息在侧栏连接或历史快照切换期间到达时仍会补齐用户气泡：重载保留实时轮次、按会话归属补放缓冲，必要时按本轮 run 补取真实用户事实。每个 run 只保留一个在途请求；空结果和临时错误按 300ms 起、最长 8 秒的退避重试，不依赖新输出。消息补齐、切换会话或离开聊天页后停止；已有用户消息的重启续跑不会重复补取。
- 浏览器可能显示原生调试提示条。主动断开调试连接会使相关操作失败。
- 在主程序的浏览器连接页撤销设备，会使其凭据和连接失效。

## 验证

```powershell
npm test
npm run test:browser
npm run test:sessions
npm run test:sync
npm run test:menus
npm run test:human
npm run test:host
npm run test:settings
npm run test:steer
npm run test:pending
npm run test:restart-process
npm run test:recovery
npm run test:connection
```

默认浏览器测试使用本机 Edge 和隔离的临时用户配置。指定其他测试浏览器：

```powershell
$env:SUGAR_TEST_BROWSER_PATH = 'C:\path\to\chrome.exe'
npm run test:browser
```

测试使用本地测试网站与确定性对话事件，不读取个人浏览器配置或调用真实模型。网页操作通过真实加载的扩展和真实 Playwright 引擎执行。`test:host` 另外通过真实 Python 宿主、ExecutionService 线程和受管理 Node 子进程调用网页工具。报告和截图写入 `artifacts/edge`、`artifacts/chrome`、`artifacts/host`。

后端测试在仓库根目录执行：

```powershell
.\python\python.exe -m pytest tests/test_browser_use.py -q
```

完整验收状态、测试范围与复现命令见 `docs/browser-extension-implementation.md`。原生侧栏的日常浏览器手动验收仍可按上述加载步骤进行；自动化 UI 检查使用扩展页面及 320／400 像素视口。
