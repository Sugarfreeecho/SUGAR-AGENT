# 桌面版右键菜单

右键菜单按点击对象提供操作，复用各区域已有的按钮、确认弹窗和后端接口。

| 区域 | 菜单操作 |
| --- | --- |
| 会话列表、会话标题 | 打开、置顶、待办、重命名、归档、导出、删除、复制会话 ID |
| 工作目录分组 | 展开或折叠、在目录中新建会话、重命名、复制路径、打开目录 |
| 用户消息 | 复制原始内容、改写、删除本条及后续对话 |
| 助手回答、代码、链接 | 复制原始 Markdown、导出文本或图片、分支、删除后续对话；代码复制、打开或复制链接 |
| 执行过程 | 复制执行内容（包括折叠的详情）、展开或折叠执行过程 |
| 工作区文件、文件预览、输入附件路径 | 预览或展开目录、系统打开、打开所在目录、复制绝对或相对路径、刷新、切换源码或预览、移除输入附件 |
| 修改历史 | 展开差分、预览文件、复制差分与路径、撤销或恢复（沿用已有状态限制） |
| 会话状态、计划、Goal | 复制内容、清除计划、Goal 的统计、暂停或继续、编辑、删除、结果审核；仅呈现当前可用操作 |
| 后台任务、持久终端 | 复用输出、连接、查看、停止、结束；输出复制、关闭视图 |
| 用户交互终端 | 复制选区、粘贴、全选、清空视图、回到底部、关闭视图；清空或关闭视图不会结束 shell |
| 标签栏、浮动窗口 | 新建、复制、分屏、移至浮窗、关闭当前或其他或右侧标签；浮窗放回主区、关闭浮窗 |
| 历史记录、聊天空白处 | 跳转消息、复制记录、回到最新消息、展开或折叠侧面板 |
| 图片、音视频 | 图片复制和保存使用原生菜单；音视频支持播放或暂停、静音、循环和复制地址 |
| 输入框、设置窗口、首启向导 | 原生撤销、重做、剪切、复制、粘贴、全选；操作定位到实际点击的页面或内嵌框架 |

菜单始终限制在窗口边界内，支持浅色、深色、紫色主题和字体缩放。长菜单可以滚动。
`Shift+F10` 或菜单键打开菜单，方向键、Home、End 导航，Enter 或空格执行，Esc 或 Tab 关闭并恢复焦点。
点击外部、实际滚动、窗口尺寸变化、窗口失焦、对象被移除或切换会话会关闭菜单。

生成中的会话禁用改写和历史删除；删除会话、删除消息、文件撤销和恢复仍由原有流程处理。
选区在菜单获得焦点之前捕获；消息复制复用原始 Markdown；终端粘贴使用 xterm 的输入管道。
前端处理的菜单阻止原生菜单重复弹出，文本编辑和图片操作保留 Chromium/Electron 的原生行为。

`frontend/src/app/modules/context-menus.js` 提供共享菜单及 `MyAgentContextMenu.bind(element, provider)` 插件接口。
provider 返回菜单项，bind 返回清理函数，生命周期结束时注销；菜单内部不会绕过现有操作的禁用状态。
生产资源由 `frontend/` 下的 `npm run build` 生成，Electron 主进程与 preload 修改需要桌面客户端重新启动。

验证入口：

```powershell
./python/python.exe -m pytest tests/test_context_menus_browser.py tests/test_desktop_context_menu.py tests/test_desktop_shell.py -q
node frontend/tests/dock-engine.test.mjs
cd frontend
npm run build
```

浏览器用例覆盖真实点击、选区、复制、导出入口、文件路径、生成状态限制、键盘、窗口边界、过期对象、标签和浮窗，以及真实 xterm 复制、粘贴和清理。
Electron 用例使用不可见测试窗口，验证自定义菜单与原生菜单互斥、原生编辑及设置页 iframe 定位；不会连接实际后端或执行 shell 命令。
