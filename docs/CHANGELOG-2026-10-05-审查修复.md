# 2026-10-05 审查修复与死代码统计

## 权限切换

- 新建聊天的 `permission_mode` 选项和直接修改权限共用 `_apply_session_permission_mode`，完成全局权限保存、执行资源清理和所有聊天的权限状态广播。
- 只在从完全访问收紧到任一受限档位时取消此前以完全访问启动的后台命令，并关闭受影响的 Agent 终端。正常权限切换返回成功，被取消的执行在记录中显示取消或中断。
- 放权以及“请求批准 / 替我审批”之间切换保留现有任务与终端；保留的 Agent 终端更新其后续输入的权限档位。用户终端保持独立。

## 终端实际工作目录

- 审批读取活跃 shell 的进程工作目录，并核对 PID 的创建时间，不再把启动目录当成当前目录。
- PowerShell 提示函数在发出私有就绪标记前同步进程的工作目录，解决 `Set-Location` 不自动更新进程 cwd 的差异。
- 正在发送输入、仍有前台任务、只因静默或超时结束等待，以及读取进程目录失败时，都按目录未知处理。授权路径重新计算不能将未知位置误还原为工作区内删除授权。

## 上下文浮窗

- 补取请求在切换聊天后成功返回时，保存至所属聊天的缓存，不覆盖当前聊天界面。
