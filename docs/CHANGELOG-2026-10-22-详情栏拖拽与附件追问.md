# 详情栏拖拽与附件追问修复

日期：2026-10-22。

## 详情栏宽度

- 拖拽时停止轨道宽度动画，内容边界与拖拽条同步，连续拖动不再使用动画中间值跳宽。
- 使用共享指针捕获机制；跨 iframe 松手、指针取消、丢失捕获、窗口失焦、收起及切换模式时结束手势，过滤其他指针。
- 统一拖拽、恢复、窗口缩放及左侧栏变化的宽度约束，push 布局为聊天区保留至少 560px。无法同时容纳详情栏最小宽度时使用全屏，保留半屏缩窗自动收起行为。
- 分离偏好宽度与当前显示宽度，临时缩窗不会覆盖用户偏好；手动全屏保留到用户主动退出。

## 带附件的立即追问

- 图片和普通文件不再因附件存在而禁用“立即发送”；等待用户回答问题的条目仍按原规则延后。
- 前端首次发送与重试均向 `/steer` 传递附件。后端复用队列的附件准入与访问校验，在追问持久化、运行中消费、模型消息、UI 事件中保留结构化内容。
- 迁移旧版本队列的附件延后标记；显式记录由待回答问题创建的延后条目。
- 附件准入期间运行若已结束，再次对账并返回幂等操作或 409，避免将追问交给已结束的运行。

## 验证

- 浏览器回归覆盖拖拽跟手、连续拖动、真实 iframe 松手、取消/失焦/收起清理、其他指针隔离、窗口与左侧栏变化、手动全屏。
- 前端运行时回归覆盖附件入队、立即发送参数、旧队列迁移及待回答问题限制。
- 后端回归覆盖图片路径、图片引用、普通文件，以及追加/打断、预先入队/直接发送、队列重载、模型与 UI 引用保留和重复请求去重。
