## 本次修复

- `session-management.js`：启动时已经发出的同一会话预取属于新服务器读取。即便本地恢复了未读标记也复用它，避免立即取消后重发。显式重新加载仍会丢弃预取，旧 DOM 缓存仍按原规则失效。
- `webui.py::_is_recoverable_react_session`：先通过验证过来源的 UI 索引判断最后一轮是否已完成。已完成会话直接排除恢复，不再仅为否定恢复而读取并长期保留完整模型/执行快照。存活或身份未知的外部所有者仍先行排除；未完成会话保留原先的宽限期、孤儿清理、持久化中断和交互暂停检查。
- `snapshot_store.py`：对同一路径的冷读取使用逐会话锁，后到的读取复用已发布快照。不同会话和写入侧不取得此锁；较旧磁盘结果不会覆盖已发布的新内存代次。没有新增结果 TTL，也没有延长页面超时。
