# SugarAgent 更新日志 — 2026 年 9 月

这个月，我们完成了数十项改进：聊天更稳、Agent 更聪明、还多了不少好用的新功能。以下是您可以感知到的变化。

---

## 🆕 本月新功能

### 右侧详情栏（Dock）
会话标题右上角的图标可以打开一个**右侧详情栏**，向左推开工作区，内置三个页面：
- **工作区文件**：浏览当前工作区的文件树
- **文件内容**：预览文件内容
- **修改历史**：查看 Agent 对文件的历史改动
可自由拖宽，每个会话独立记忆打开状态。

### 改动审查（Change Review）
Agent 每次**改动文件后，您可以查看具体的行级差异（diff）**，并且：
- 多文件改动分别列出，**每个文件可单独撤销**，也可一键全部撤销
- 撤销后如果反悔，还可以**一键恢复**（Restore / Restore All）
- 临时文件写入不会进入审查列表，统计口径更准确

### 图片理解管线
会话中的图片现在可以被**持久化理解**——贴图后 Agent 能理解图片内容，且会话历史中图片稳定保留。

### 围棋来了 🎮
游戏竞技场新增**围棋（Go/Weiqi）**：支持 9/13/19 路棋盘、提子、劫、计分，和五子棋一起在聊天里对战。

### 目录授权审批
允许 Agent 访问工作区以外的位置时，改为**按目录授权、随会话绑定**：
- 授权一个目录后，其下的操作都会沿用该授权（含复制/分支/子会话）
- 删除文件的保护范围跟随授权目录，更精确

## ⚡ 更顺滑的体验

- **"黄点"误报修复**：会话已经结束却显示"运行中"的问题从根本上解决——最终消息落盘即刻转为完成态，旧快照/轮询不再把已结束的任务"复活"
- **流式输出更稳**：对账、网络断连、陈旧快照场景下运行中的流不再中断；锁屏回来后延迟回答的问题也能正常恢复
- **滚动体验优化**：打开有内容的会话直接落位最新结果、图片加载不再打断滚动、跨窗口切换会话不再误判乱跳
- **新会话秒开**：点"新会话"先打开本地草稿页，首次发送才真正创建（不再有 6–10 秒的卡顿等待）
- **会话列表更快**：列表与待处理计数不再每次轮询都读磁盘，秒级刷新

## 🛡️ 审批更清晰、更少打扰

- 审批卡片显示**拦截原因**（命中哪条规则）+ 命令风险与目的
- 处理完的审批/提问卡片可以**展开查看完整内容**（只读）
- 本机调试命令（如访问 `127.0.0.1`）不再被误判为危险操作
- Shell 相对路径按实际工作目录判定审批归属，更准确

## 🧠 模型与传输改进

- 模型配置迁移与**切换类型风险提示**（跨类型切换会提示历史截断、tool_call_id 错位风险）
- 每个模型档案支持**自定义请求头**（如 OpenCode 网关所需）
- 连接错误**先就地重试**再切换模型；首 token 竞速恢复
- 模型调用失败时**保留原始错误原因**（不再被后续错误覆盖）
- Token/s 统计改用纯生成段计算，更贴近真实速度
- 新增 TTFT（首 token 延迟）诊断工具，持续优化响应速度
- 模型表更新至 **445 个模型**（OpenRouter 快照）

## 🔧 其他

- 内置插件改为**按目录自动识别**——放入插件包即被识别，无需登记
- 提问卡片：全部回答完才能"提交"，避免误操作
- 本地 UI 性能记录器（协助定位卡顿）
- 修复 glm-5.3-flash 工具调用参数解析问题
