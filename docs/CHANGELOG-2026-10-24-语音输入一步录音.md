**语音输入改成一步录音：录音条贴在输入框上方（2026-10-24）**

原来的流程是「点麦克风 → 弹出一个对话框 → 点开始录音 → 说完再点停止并识别」。三步才录上一句话，弹窗还要自己算位置、挡住消息、在浅色主题下发灰。

**一步开始。** 点麦克风直接录音，再点一下（或点「完成」）结束。录音期间麦克风变红并带脉冲，`aria-pressed` 为真。

**录音条取代弹窗。** 它绝对定位在 `.composer-row` 上方，从左到右是：红点、计时、实时波形、「再点一下麦克风结束」，右侧是「取消 / 完成」。不改输入框高度、不遮挡草稿，位置固定不再跟随滚动重算。

**波形。** 由 `capture.level()` 的 RMS 开方映射，再叠加一条固定包络——安静时也不会塌成一条虚线，说话时能看出起伏。

**状态都在同一条里。** 检查中、录音中、识别中、待确认、出错共用一条录音条，按钮按状态显隐：

| 状态 | 内容 | 按钮 |
|---|---|---|
| 录音中 | 红点 + 计时 + 波形 + 提示 | 取消 / 完成 |
| 识别中 | 「正在识别…」 | 取消 |
| 待确认 | 识别结果（可滚动） | 取消 / 插入 |
| 未配置 | 缺什么就说什么 | 语音设置 / 取消 |
| 完成 | 「已插入草稿」 | 无，1.2 秒后自动收起 |

**设置入口。** 右键麦克风，或长按 0.55 秒；长按后会抑制随后的 click，不会顺手又开一次录音。

**样式跟着主题走。** 只用 `--surface-glass`、`--border-hover`、`--accent-rgb` 等既有变量；`prefers-reduced-motion` 下关闭入场动画、脉冲和波形过渡。浅色与深色实机截图见 `workspace/tts-light-samples/dock-theme-light.png`、`dock-theme-dark.png`。
