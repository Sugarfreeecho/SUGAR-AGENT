# `ls` 工具改动检查清单

## 工具暴露与兼容性

- [x] LLM 工具定义中只暴露一个 `ls`。
- [x] LLM 工具定义中不再重复暴露 `list_dir`。
- [x] 执行层保留 `list_dir -> ls` 映射，兼容旧会话和历史工具调用。
- [x] `ls` 与 `list_dir` 继续归类为只读工具并使用相同权限检查。

## 目录列表行为

- [x] 普通目录名称以 `/` 结尾。
- [x] 目录不计算大小和行数，显示 `—`。
- [x] 压缩包不计算大小和行数，显示 `—`。
- [x] 压缩包扩展名匹配不区分大小写。
- [x] 支持 `.zip`、`.zipx`、`.7z`、`.rar`、`.tar`、`.tgz`、`.tbz`、`.tbz2`、`.txz`、`.gz`、`.bz2`、`.xz`、`.zst`、`.cab`。
- [x] 非文本文件保留文件大小，但不计算行数。
- [x] 受保护的敏感资源仍不会出现在列表中。

## 文本文件行数

- [x] 仅对已识别的文本、配置和源码文件统计行数。
- [x] 覆盖常见文本格式，如 `.txt`、`.md`、`.json`、`.yaml`、`.csv` 和 `.log`。
- [x] 覆盖常见源码格式，如 `.py`、`.js`、`.ts`、`.html`、`.css`、`.java`、`.go` 和 `.rs`。
- [x] 覆盖无常规扩展名的文本文件，如 `Dockerfile`、`Makefile`、`LICENSE`、`README` 和 `.gitignore`。
- [x] 覆盖 `.env` 及 `.env.*` 配置文件。
- [x] 未识别扩展名默认不扫描，避免误读二进制内容。
- [x] 空文本文件显示 `0` 行。
- [x] 无权限或读取失败显示 `?`。
- [x] `include_line_counts=false` 或 `LS_INCLUDE_LINE_COUNTS=0` 时不扫描任何文件行数。

## 大文件性能保护

- [x] 行数统计前先读取文件元数据并检查大小。
- [x] 默认只扫描不超过 5 MiB 的单个文本文件。
- [x] 超过上限的文本文件不打开、不遍历完整内容。
- [x] 超限结果显示为 `— (>5.0 MiB)`，使跳过原因可见。
- [x] 可通过 `LS_LINE_COUNT_MAX_BYTES` 调整单文件上限。
- [x] 非法的 `LS_LINE_COUNT_MAX_BYTES` 值回退到默认 5 MiB。
- [x] `.env.example` 已提供默认配置示例。
- [x] 高级设置页面已登记配置项及说明。
