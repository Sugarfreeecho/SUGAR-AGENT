# 页面加载与缓存优化总账

整理日期：2026-10-22。覆盖此前设置/目录缓存、会话加载恢复、交互预热，以及最新的历史回放与后台诊断修复。本次只整理已有代码与测量记录，没有重新启动模型任务，也没有新增一轮性能基准。

## 结论与统计口径

已经证实的收益集中在减少重复工作、缓存重开、历史回放完成时间和减少连续阻塞。**没有证据支持“所有页面统一快了若干倍”，多会话生成后的稳定加载仍未完成验收。**

尤其需要补充上一轮只重点报告中位数的局限：最新整页有限对照中位数减少 18.7%，但三次正式测量的**平均耗时增加 28.6%**。不能只挑中位数而将其写成“整页已稳定提速”。

所有百分比均为耗时变化，减少比例 = `(修改前 − 修改后) / 修改前`。各阶段可能并行，不相加为整页收益。

证据分为：

- **固定工作量对照**：相同数据、实际实现、交替顺序，通常每组一次预热、三次正式样本，取正式样本中位数。
- **在线有限对照**：同会话或固定前端产物，但服务端、机器负载及异步控件未完全固定，只能作为观察证据。
- **首次/再次打开**：优化后同一轮首次与重复打开的差异，衡量复用体验；不是修改前后 A/B，首次也不等于后端完全冷缓存。
- **机制/功能验证**：证实请求合并、有界工作或状态正确，没有足够耗时数据计算收益。

## 一、具体改了哪些内容

| 范围 | 增加或调整的优化 | 数字证据与限制 |
| --- | --- | --- |
| Agent 设置外壳 | 去掉重复 GET 探活；保留同会话/工作区 iframe；上下文变更重建；可提前预加载隐藏 iframe | 有首次/重开时间；没有旧版同条件整页 A/B |
| 设置分区 | 常规、模型、技能、Hooks、插件保留 DOM；相同数据不重建；后台校验；编辑中迟到响应不覆盖操作 | 重开多数更快；MCP、权限及自定义分区保留专门重载/清理流程 |
| 前端目录缓存 | 模型、Skill、扩展、MCP 工具、工具搜索配置共用缓存；同源 iframe 共享；相同 GET 合并；通常 30 秒有效，MCP 发现中约 1 秒 | 同一轮重复打开可见收益，具体见下表；缓存读取仍需克隆独立副本 |
| 缓存失效 | 保存、导入、启停后失效；跨窗口发送失效通知；失效前的旧响应不能回填新缓存；失败允许重试 | 正确性保障，无单项加速百分比 |
| 模型选项 | 列表缓存；列表与会话绑定并行；绑定及必要权威刷新仍实时读取 | 有菜单首次/再次打开数据，无单项代码 A/B |
| 加号各页签 | 当前页签按需加载；Hooks/Plugins 共用扩展快照；隐藏菜单不重绘；修复 SVG 替换反复触发预热的循环 | 修复不稳定点击；不能将全部菜单差值归给缓存一项 |
| 交互预热 | 鼠标停留/聚焦约 140 ms 后预热目标；离开取消未启动工作；串行预热；隐藏页面、待处理输入及空闲不足时延后 | 有调度测试；无在线统一收益百分比 |
| 窗口反馈 | 先显示外壳/选中状态再做重工作；已加载设置立即显示；确认框先关闭再交付结果 | 隔离负载用例打开/关闭下一帧约 7.5/7.9 ms；不是在线前后对照 |
| 后端扩展目录 | 复用发现报告；展示缓存 10 秒；同代构建合并；过期可先返回旧展示数据、后台单次刷新 | 目录微基准 28.598→4.217 ms；不参与执行授权 |
| MCP 加载 | 已知服务器/工具先显示；远端发现后台继续；发现期间轮询局部列表；独立请求并行；保留草稿 | “内容已显示”不表示所有远端 MCP 已连接完成 |
| 设置静态文件 | 匹配版本的资源使用浏览器长缓存；其他请求保留校验；设置 HTML 不缓存 | 机制已实现，未测独立端到端百分比 |
| 会话切换 | 状态校验与内容恢复并行；完整缓存先显示；摘要请求按会话合并；取消和 epoch 隔离 | 去除原先最多 450 ms 的串行预检门槛；这是上限，不是每次实测节省 450 ms |
| 首次恢复 | 上次会话历史提前预取，与侧栏、待处理交互并行，选中后消费同一响应 | 有整页绝对值；无完整冷启动同负载 A/B |
| 历史首屏 | 最近最多 200 条事件；旧页有界加载；避免首屏不足时立即补回全部历史；保留当前未完成执行记录恢复 | 首屏工作量有界；旧内容需要继续翻页，不能声称全历史同量读取加速 |
| 初始滚动 | 首次/刷新直接定位最新消息，取消约 2.1 秒动画等待 | 滚动阶段 2094.1→34.6 ms，减少 98.3% |
| 历史与流式调度 | 按约 12 ms 时间预算让出；移除按 64 条额外让出；优先 scheduler.yield、回退 MessageChannel/定时器；SSE 共享入口 | 固定回放完成时间减少 45.2%/50.7%；单条昂贵渲染仍可能超预算 |
| 历史渲染布局 | 隐藏树不反复测量高度/溢出，显示后统一测量；排除内容子树的无效翻译 | 隐藏历史重复 200 次无布局读取；没有单项在线百分比 |
| 最新侧栏优化 | 候选标题首帧后合并测量；中文模式跳过新增节点翻译；关闭会话菜单跳过布局 | 合并方案在线有限对照：整页减少 18.7%，侧栏减少 21.4% |
| 浏览器连接 | 后台会话 SSE 读取器最多 3 个，优先当前会话；释放观察者不会停止 Agent | 独立 Edge 实验证实避免同源连接池占满；不是四路真实生成的压力验收 |
| 附件图片 | 接近可见区域再下原图；最多并发 2；共享下载、尺寸占位、取消及 URL 释放 | 有请求预算验证，未量化单项整页收益；图片显示成本向实际查看时转移 |
| 插件会话 UI | 一个投影请求在途；合并变化；约 200 ms 调度；隐藏页面延后；未变化保留 DOM/焦点 | 100 个变化事件测试只触发 2 次请求，峰值在途 1；缺少旧版相同输入请求数，不计算“减少 98%” |
| 旧会话路径/计数 | 避免扫描备份和产物；沿 UUID/subagents 目录查找；只统计可见会话及后代 | 计数范围 419→167，减少 60.1%；这是工作范围，不是耗时减少 60.1% |
| 后端状态读取 | 状态构建在进入 executor 前合并；插件静态请求复用目录；继续检查用历史索引；跳过运行中无意义检查；仅复制所需快照字段 | 已定位并移除全日志重放、重复深拷贝热点；缺少各项独立耗时 A/B |
| 事件循环 | 权限健康检查、兼容校验等同步重工作移出 ASGI 事件循环 | 有回归验证，无统一加速百分比；线程中的 CPU 工作仍可能争用 GIL |
| 后台执行统计 | 按请求拆分 JSON 编码，保留完整记录和原子替换 | 旁路线程最大停顿减少 95.5%；文件写入总耗时基本不变 |
| 线程监控 | Windows 系统查询允许其他线程运行；失败回退；采样昂贵时降低频率 | 旁路线程最大停顿减少 73.4%，单次采样反而增加 18.3% |
| 上下文与排序 | 历史不改当前 token；迟到读取不能覆盖新值；隔离 provider/本地计数缓存；分页执行顺序使用持久身份辅助比较 | 正确性修复，不计为性能收益；修复 ad986 新消息插入旧区域问题 |

## 二、有耗时对照的收益

| 项目 | 修改前→修改后 | 耗时减少 | 证据等级/边界 |
| --- | ---: | ---: | --- |
| 扩展目录读取 | 28.598→4.217 ms | **85.3%**，约 6.8 倍读取速度 | 微基准：重建与缓存命中，7 插件，非整页 |
| 首次滚动 | 2094.1→34.6 ms | **98.3%**，省 2059.5 ms | 同会话阶段在线观测 |
| 当轮首次整页 | 3730→2082 ms | **44.2%** | 同会话 9 消息，DOM 6093/5992；主要收益是滚动，早于切片修改 |
| 固定历史回放，1x | 254.0→139.2 ms | **45.2%** | 固定 200 事件、1152 DOM，实际 hydrate 循环 |
| 固定历史回放，4x | 2572.6→1267.9 ms | **50.7%** | 同夹具、4 倍浏览器 CPU 降速 |
| 最新整页，4x | 10424→8478 ms | **18.7%**，省 1946 ms | 固定前端产物的在线有限对照，后端负载未固定 |
| 最新侧栏，4x | 6764→5318 ms | **21.4%**，省 1446 ms | 与上一行同组，不能与整页相加 |
| 统计写入时旁路线程最大间隔 | 393.0→17.8 ms | **95.5%** | 固定约 9.2MB、1317 请求的独立进程实验，非 HTTP/INP |
| 线程枚举时旁路线程最大间隔 | 62.3→16.6 ms | **73.4%** | 对同一进程 36 线程只读采样，非 HTTP/INP |

初始滚动省去约 2.06 秒，而当轮整页只减少约 1.65 秒，其他成本和阶段重叠会影响总结果，不能直接相加或归功给后来的切片。

## 四、下降、代价与未证实收益

| 项目 | 观测结果 | 解释及当前处理 |
| --- | --- | --- |
| 旧版 setTimeout 切片 | 隔离机制实验：1x 不切片 111.2→定时器切片 341.9 ms，**增加 207.5%**；4x 764.8→3885.7 ms，**增加 408.1%** | 完成更慢、按键确认更快，是响应性与完成时间的交换；旧调度已被替换。该机制实验与最新实际循环 A/B 不是同一套实现，不能把两表跨行拼接 |

| 统计文件写入总耗时 | 439.5→435.9 ms，仅减少 **0.8%** | 视为基本不变；主要收益是其他线程能运行，不是文件吞吐 |

| 最新整页平均耗时 | 三次正式样本平均 10109.7→12997.3 ms，**增加 28.6%**；侧栏平均 8200→9966 ms，增加 21.5% | 不能只用变快的中位数宣称整体收益；负载没有锁定，同样不能证明退化全由代码导致 |
| 内存与长期运行 | 保留 iframe、分区 DOM、目录/会话缓存会占用更多常驻内存；缓存读取克隆也有成本 | 尚无完整长期内存/命中率/逐会话堆大小 A/B，不宣称已解决长期内存增长 |
| 有界历史与懒加载 | 首屏不再一次加载全部历史/图片 | 等待成本部分转移到向前翻页和实际查看附件，不是所有内容都提前就绪 |

## 五、整页当前状态与未完成验收

最终前端发布后的实际 ad986 会话：首次可用 **2.806 秒**、刷新 **2.522 秒**，实例 0 个生成任务，无人工降速、无页面脚本错误。刷新侧栏约 813 ms、回放约 81 ms、后端历史快照约 1856 ms。

这不是统一的“最终比最初快多少”：最早出现过 35–60 秒页面未就绪、249 秒侧栏构建、172 秒历史请求，其中数据、负载、会话与版本都不同；不能拿失败/超时与空闲实例的 2.5 秒算几十倍加速。

最新固定产物在线对照虽然中位数改善，修改后仍有一次 **23.553 秒**的波动；此前 4 个真实任务时历史请求也发生 20 秒超时，另轮并行生成测试 60 秒内侧栏未就绪。**多路真实生成时的稳定性没有通过同负载验收。** 浏览器 4 倍 CPU 降速只模拟前端 CPU 变慢，不等同于四个 Agent 同时生成。

最新整页对照完整汇总如下，每侧仅 3 个正式样本，不据此估计 P95/P99：

| 指标 | 修改前 | 修改后 | 耗时变化 |
| --- | ---: | ---: | ---: |
| 三次正式样本 | 10.424 / 8.798 / 11.107 秒 | 6.961 / 8.478 / 23.553 秒 | 前两次更快，第三次明显更慢 |
| 中位数 | 10.424 秒 | 8.478 秒 | 减少 18.7% |
| 平均值 | 10.110 秒 | 12.997 秒 | **增加 28.6%** |
| 本组最慢一次 | 11.107 秒 | 23.553 秒 | **增加 112.1%** |

平均值及最慢一次的退化是这组真实记录的一部分；后端请求耗时也波动，不能直接归因为前端修改，但更不能将该组数据解读为稳定性已改善。

目前能确认：目录/设置重开和固定历史回放有收益，重复扫描及连续阻塞减少；尚不能确认：任何负载下刷新都快、长时间运行不再退化、多个生成任务时不再加载失败。后台扫描、历史投影/恢复读取、冷索引与服务端资源争用仍是后续重点。
