# 子代理共享心跳与工具schema计数复用（2026-11-02）

本批针对[上次真实运行复核](acceptance-since-2026-10-27-to-2026-11-02.md)中的子代理交付心跳、工具目录披露两处本地热点。实现完成、受控收益和生产达标分别记录；不以局部基准改写原3491个生产轮间的26.32%达标率。

## 1. 实现与事实边界

1. **移除子代理交付前重复的metadata心跳。** `agent_subagent._execute_subagent_run` 已通过 `execution_metrics.start_run` 注册精确child/run的共享15秒心跳泵，列表优先读取该运行心跳。原先在事件交付锁内再等待 `patch_subagent_metadata`，重复了存活维护，且阻塞后续journal/UI提交和发布。本批去掉该重复写入；开始/终结metadata、共享泵注销、取消收敛和所有权守卫保留。原始metadata心跳字段成为最近生命周期快照，不再每15秒改写。旧23477ms心跳span包含等待，不能全部认定为JSON编码或文件写本体，更不能将其与父包络重复相加。
2. **相同schema跨列表复用计数。** `agent_tokenizer` 保留原32项身份缓存，新增32项/4MiB（UTF-8序列化字节）的稳定JSON全文内容缓存。16把固定锁避免同内容并发重复编码，摘要仅选锁、全文决定相等；超大条目绕过内容缓存与协调锁。tokenizer对象、加载状态、计数函数或编码失败代次变化使两级缓存失效，临时encode失败的字符估算不缓存，下次可以重试。SHA1指纹格式保持，原落盘基线继续有效。
3. **披露计算等待工作线程完成。** `build_combined_tool_registry_for_session` 用 `await asyncio.to_thread(tool_search.assemble, …)` 计算私有注册表，释放协调循环处理其他任务。取消可丢弃纯计算结果；不游离任何事实写入。实时权限/档案/来源过滤和执行授权不缓存、不跳过。

主代理和前后台子代理共享上述目录构建与计数实现。用户轮、助手/工具结果、摘要与所有权转交仍在下一API前提交；子代理UI/journal原子批次、逐项顺序与取消时已开始写入的结算保持。

对应设计：[02/10 UC-2J14](../Agent%20设计（用户方案）/02-ReAct运行时/10-子代理任务生命周期与事件循环隔离方案设计-UseCase清单.md)、[03/01 UC-3A6](../Agent%20设计（用户方案）/03-工具系统/01-注册表与描述符方案设计-UseCase清单.md)。
