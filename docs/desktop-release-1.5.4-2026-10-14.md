# SugarAgent 1.5.4 桌面安装包

构建日期：2026-10-14。安装包输出：`packaging/build/dist-1.5.4/SugarAgent-Setup-1.5.4-x64.exe`。

## 本次安装性能优化

- 飞书 SDK 的完整代码和预编译字节码合并为一个 ZIP，便携 Python 通过 `.pth` 直接导入；依赖元数据与 pip 卸载/升级记录保留。
- PPT 的 11,631 个 SVG 合并为归档与完整索引，图标同步、SVG 解析和预览按使用提取。首次启动复制归档，离线图标库完整保留。
- 两处 pip 安装使用 `--no-compile`，构建期 Python 使用 `-B` / `PYTHONDONTWRITEBYTECODE=1`。
- 在全部依赖自检、版本探针、`pip list` 结束后清理松散字节码，包含复用依赖中的历史缓存；SDK 与标准库 ZIP 内的字节码保留，应用运行期仍可生成缓存。
- 构建前后检查归档布局、松散缓存与用户目录，防止旧载荷重新进入安装包。
