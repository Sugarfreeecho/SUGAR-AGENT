# 分组会话管理

工作目录和时间分组（含置顶时间组）的右侧三点菜单提供「会话管理」。工作目录菜单保留重命名、复制路径和资源管理器入口；时间分组只展示会话管理。

管理面板读取分组的全部会话，不受目录前 5 / 10 条显示限制。支持按名称、ID、最近提问及工作目录筛选，多选和全选当前筛选结果。切换筛选保留已选项，计数及操作确认涵盖全部已选会话。

- **批量删除**：先确认数量及会话名称，再逐项调用现有 DELETE 接口。服务端成功后才清理本地记录、缓存和停靠页面；失败项保留选中并显示原因。删除当前会话后在批次结束时统一切换到其他会话，全部删空则进入新会话。
- **迁移工作区**：从已有工作目录选择，或使用目录选择器新增目标。确认后逐项调用现有 work-dir 接口，保留运行中会话、托管工作树、目标路径和授权目录的现有校验。会话历史和附件仍在共享存储，不搬动工作区文件。
- 操作期间显示进度并防止重复提交；每项分别反馈结果。批次结束后刷新侧栏，失败项可再次操作。关闭面板恢复原焦点与页面滚动状态。

实现位于 `frontend/src/app/modules/session-group-manager.js`，接入共享分组菜单与渲染层；没有新增批量后端接口。单会话删除与批量删除共用本地清理函数。

浏览器测试 `tests/test_session_group_manager_browser.py` 覆盖两种分组入口、隐藏会话、筛选全选、取消确认、部分失败、失败重试、当前会话切换、目录选择及确认层级。
