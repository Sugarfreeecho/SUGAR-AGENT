## 子代理

- **启动可靠性**：分配的首条 user 消息在所有权转交子 ReAct 之前先落盘；首轮提交失败不再静默——释放预约并按失败终结化（任务行/元数据/final/父级通知）。
- **预约期受控**：任务挂载前即可打断（删除/停止/中断不再有“已预约但不可取消”窗口）；归属按 run-id 精确判定，陈旧的启动尝试不会覆盖更新的运行；重启对账把 `pending` 一并收敛。
- **子会话可见性**：运行中的子代理被视为活跃子会话——状态/忙碌守卫正确，子会话页流保持唤醒（仅当无本地 worker 时才收流），不会被 `/chat` 再起竞争运行；子会话内提交的 steer 由子代理**顺序消费**（append 语义）。
- **前端**：`subagent_created` 生命周期帧先注册 pending 子行（启动前即可见）；目录刷新按“父会话+可见会话”节流。
- **存储**：任务索引并发加锁、不再覆盖子会话元数据（worktree 根/模型档案/只读标记保留）；JSON 写入原子化 + Windows `replace` 重试。
