# SugarAgent 版本更新预览（2026-08-16 → 2026-09-07）

过去三周，SugarAgent 完成了一轮大版本升级：底层更稳、用起来更顺手、能玩的内容也更多了。以下是面向普通用户的更新说明。

---

## ✨ 聊天体验更顺滑了

- **文字输出不再"跳来跳去"**：回复边生成边流畅滚动，打开有内容的会话会直接定位到最新回复，不再闪烁或来回抖动。
- **聊天历史里的图片不会丢**：图片在会话中能正常保留和显示，加载图片时滚动也不会被打乱。
- **多窗口同时开着也不打架**：在多个窗口/标签页切换会话时，滚动位置更准确，不会误判成"冷加载"而乱跳。
- **深色主题更精致**：文字和表格的配色重新校准，阅读更舒适。

## 🛡️ 更安全，但更少打扰

- **审批卡片更清楚**：需要你确认的操作，会明确告诉你"为什么被拦"（比如命中删除规则），不再只有模糊的风险提示。
- **本地调试不再烦人**：访问本机地址（如 `http://127.0.0.1`）的调试命令不再被当成危险操作反复弹窗。
- **目录级授权**：允许 Agent 访问工作区以外的文件夹时，授权更精细——按目录授权、随会话继承，删除文件的保护范围也更准确。

## 🤖 Agent 干活更聪明、更持久

- **长任务不容易"卡住"**：修复了任务运行中停顿的问题，每一轮处理都更快。
- **断线自动重连**：网络临时出错时会先原地重试，而不是直接切换模型或失败。
- **后台任务恢复更稳**：会话恢复改由服务端统一接管，前端不再抢跑，多开窗口也不会重复启动任务。
- **中断尾巴可清理**：运行中断留下的"红色尾巴"，清理后不再一直报警提示。

## 🎮 新增娱乐功能：围棋

- **游戏竞技场新增围棋（Go/Weiqi）**：支持 9/13/19 路棋盘、提子、劫、计分，和已有的五子棋一起，直接在聊天里对战。

## 🧩 插件能力大扩展

- 更多内置功能（目标管理、待办、桌面通知、搜索等）都以**插件**形式提供，更灵活、可独立开关。
- 插件页面支持按类型分组折叠，找起来更方便。

## 🖥️ 界面小细节

- 执行过程块可以**折叠/展开**，界面更清爽。
- 提问卡片改进了按钮：**全部问题回答完才显示"提交"**，更不容易误操作。
- 会话支持打"**待办**"标签，目标完成会有"**待审核**"标记。
- 左下角版本号会随每次更新自动刷新，方便你确认是否已是最新版本。

---

*以上为 8 月 16 日以来主要可见变化的通俗版总结。更详细的技术变更可参阅 `docs/CHANGELOG-2026-08-*.md` 与 `docs/CHANGELOG-2026-09-*.md`。*
