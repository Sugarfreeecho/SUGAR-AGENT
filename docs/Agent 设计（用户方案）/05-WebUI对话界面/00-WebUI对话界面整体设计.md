## 1. 一句话定位

用户与 Agent 的**唯一操作界面**：消息流、实时状态、面板与卡片，全部由 SSE 事件驱动、可断线续看。

## 2. 目标 / 非目标

**目标**
1. 对话全流程零刷新（发送→流式→工具→审批→完成）；
2. 一切面板（子代理/审批/档案/技能/工作区）在同一外壳内协作；
3. 断线、刷新、重启三种"意外"都不丢上下文。

**非目标**
- 不做移动端专门适配（响应式范围内尽力）；不做多用户登录体系。

## 4. 跨功能不变式

1. **事件驱动**：界面状态 = 事件流投影；刷新后可从历史重建。
2. **失焦不丢**：页面不可见时事件继续累积（presence 上报策略）。
3. **会话隔离**：切换会话时各面板状态重置/重载（互不串扰）。
4. **附件引用化**：上传回执、历史与 follow-up 队列使用耐久附件引用；预览 blob 只存在于页面内，并在末节点移除时释放。
5. **寻址即视图**：打开子代理 = 在主对话区寻址其会话（父入栈/返回还原）；不新建独立视图容器，全部复用会话切换与 stash/restore 机制。
