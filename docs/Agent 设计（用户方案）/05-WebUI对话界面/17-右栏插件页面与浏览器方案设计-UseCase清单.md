# 右栏插件页面与浏览器 · 功能方案设计（UseCase 清单）

- 版本：2026-10-25 v3（导航与桌面 IPC 校验、会话删除回收和资源上限）。
- 状态：已实现；Web 与真实 Electron 的定向实测已通过，回归与构建记录见末节。
- 上级：08《详情栏》、06/04《插件 UI 命令与后台服务》。源码对照见 [`../../plugin-details-sidebar-and-dsh-browser-analysis-2026-10-22.md`](../../plugin-details-sidebar-and-dsh-browser-analysis-2026-10-22.md)。

## 1. 功能定位

插件业务页面统一在右侧详情栏中打开。设置中心继续管理配置；已有内嵌设置保持在设置分区。通用浏览器是另一种右栏页面，Web 使用 iframe，桌面使用隔离的 Electron webview。两类页面共用标签、分栏、浮动、全屏和生命周期管理，但访问策略分别处理。

## 2. UseCase

### UC-5R1 声明插件右栏页面
- **触发**：插件声明 `capabilities.ui["details.tab"]`；旧插件的 `navigation` 页面贡献由宿主兼容映射。
- **预期现象**：开始页固定展示「工作区文件 / 修改历史 / 浏览器 / 插件」四个类型入口；插件贡献集中在独立的「插件」（`plugins`）页面中选择，不在开始页平铺。选择后打开完整插件页面，重复打开聚焦已有标签。
- **列表行为**：按声明顺序、标题与页面标识排序；隐藏内嵌设置项；启停插件后实时更新，包括浮动和重新打开的列表；没有页面时显示空态，浏览列表不会预加载插件 iframe。
- **规则与边界**：页面地址由宿主生成，只使用插件已声明的 `web.entry`；插件不能借此注册任意地址或任意宿主脚本。可信内置渲染器沿用物理目录和系统插件校验。
- **依据**：`app/plugins/ui.py`、`plugin-ui-slots.js`、Dock 注册表及页面宿主。

### UC-5R2 统一打开与上下文
- **触发**：聊天插件按钮、设置中的页面入口、输入框页面动作或 `MyAgentDock.openPluginPage()`。
- **预期现象**：右栏展开；同插件同页面同绑定会话重复打开聚焦已有标签；会话页面自动接收会话 ID，应用页面不要求用户创建会话。
- **规则与边界**：布局 surface 身份与业务 session 身份分别管理，子代理页面不能误绑定父会话。设置浮层通过已校验的消息转交打开请求，并遵守未保存配置检查；独立设置页通过主页面深链打开。
- **依据**：Dock 页面 API、`modules/settings.js`、`static/settings/{core,plugin_sections,sections_ext}.js`。

### UC-5R3 页面保活、可见性与回收
- **触发**：切标签、切会话、分栏、浮动、收起、关闭或停用插件。
- **预期现象**：已访问的插件页面和桌面浏览器保留浏览上下文；隐藏时暂停插件轮询；关闭或停用后释放页面、连接、事件监听与待完成挂载。
- **规则与边界**：不能用缓存 DOM 对象代替页面保活；异步结果不得挂回已关闭页面。页面消息同时校验 origin、source 和当前标签归属。同源插件 iframe 沿用现有信任模型，不宣称形成第三方权限沙箱。
- **依据**：Dock 页面宿主、页面桥接脚本、插件轮询处理。
- **2026-10-25 补充**：删除会话成功后释放该会话独占的页面与布局；普通会话切换继续保活。工作区图片尺寸缓存使用有界 LRU。桌面 guest 关闭有等待预算，工作区存储分区设置容量上限，达到上限明确拒绝新分区而不清除已有登录状态。

### UC-5R4 右栏浏览器
- **触发**：开始页浏览器入口或 `MyAgentDock.openBrowser(url)`。
- **预期现象**：提供地址栏、后退、前进、刷新和系统浏览器打开；桌面观察真实 URL、标题和导航历史。样式对照 DSH `ui-sidebar-browser`：38px 工具栏、28px 透明工具按钮、28px 内嵌地址栏、聚焦时显示前往按钮、居中空态与加载态；不可观测导航显示「地址已变化」标记。浏览器标题使用 14px 地球图标，工具图标直接复用 DSH `ui-primitives` 的 regular SVG 路径；浮动模式保持相同标题。
- **规则与边界**：地址输入仅 HTTP(S)，拒绝嵌入凭据和应用自身地址；Web 使用 opaque-origin sandbox 并保留站点防嵌入限制，对不可观测导航标明地址未知，不能承诺阻止网页自己发出的所有网络请求；桌面主进程额外阻止 guest 对应用 Host 的网络请求，guest 禁用 Node、保留 sandbox/context isolation/web security，不获得宿主 preload，通过批准的租约及独立存储分区挂载。页面和布局为内存状态，不跨刷新恢复。
- **依据**：Browser 控制器、Web iframe 载体、Electron browser guest 与 preload 桥。

### UC-5R5 现有页面迁移
- **触发**：打开 Goal、Team、Game Arena、刷 B 站、线程监控等完整界面。
- **预期现象**：页面在右栏正确加载资源、跟随主题语言字号、适应窄栏；返回入口关闭面板内容；棋盘可使用全屏。
- **规则与边界**：账号配置保留设置内嵌；只提供资源目录但没有 Web 入口的插件不会生成空页面；本次不增加模型操作当前网页的工具。
- **依据**：各插件 `web/`、manifest、宿主页面桥接。
