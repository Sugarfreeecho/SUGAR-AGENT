# 顶部通知与权限警示视觉系统 · 功能方案设计（UseCase 清单）

- 版本：2026-09-21 v1（覆盖至：当前工作区）
- 用途：逐条审查（四字段格式）；核对顶部待办提示与权限警示是否共享同一套玻璃视觉语法，且"常驻待办"与"瞬时警示"两类语义不互相混淆。
- 适用实现：`frontend/src/app/modules/human-interactions.js`、`frontend/src/app/modules/permissions.js`、`frontend/src/styles/app.css`、`frontend/src/shell-body.html`、`frontend/index.html`。
- 上级：`00-WebUI对话界面整体设计.md`

---

## 1. 功能定位

页面内顶部区域的两种提示：

- **待办条**（常驻状态）：有未处理的审批/问答时出现，两态互切——展开为单行条（计数与"立即处理"），超时收起为品牌图标右上角的小铃铛徽章；数量归零即消失。
- **红色警示条**（瞬时事件）：完全访问开启、出站防护降级/部分、MCP 注册失败等系统级警示；单行展示、只有一个"确认"操作、自动消失，不沉淀为徽章。

两者共用同一玻璃底与内环描边语法；同时出现时"警示在上、待办让位"。

## 2. UseCase

### UC-5L1 待办条两态切换
- **触发**：待处理数量（审批 + 问答）发生变化；或用户点击品牌图标右上角的铃铛徽章。
- **预期现象**：数量由 0 变正 → 顶部展开单行条（图标 + "待处理事项" + 全局/当前会话计数 chip + "立即处理" + 关闭按钮）；展开 6 秒后自动收起为小铃铛徽章（不显示数字，带未读点）；点击铃铛可在展开/收起间切换；悬停或键盘聚焦期间不自动收起；数量归 0 时展开条与徽章同时隐藏。
- **规则与边界**：数量只出现在展开条的 chip 与读屏标签里，徽章不显示数字；只有数量指纹（总数:问答:审批）变化才触发重新展开；会话/全局明细保留为读屏文本，不占用单行条版面；关闭按钮只收起，不改变待办数据。
- **依据**：`human-interactions.js::updateHumanInteractionBanner / setHumanInteractionBannerExpanded / updateSidebarBrandNotice`；`app.css` 的 `.human-interaction-banner`、`.sidebar-brand-notice`；`shell-body.html` 与 `frontend/index.html` 的对应标记。

### UC-5L2 红色警示条统一表面
- **触发**：完全访问模式开启提示、出站防护降级/部分提示、MCP 注册未完成/失败等系统级警示。
- **预期现象**：所有来源复用同一条玻璃单行条——红色警示图标 + 红色内环描边 + 单行文案（超长省略、悬停显示全文）+ 唯一"确认"按钮；约 9 秒自动消失，悬停/聚焦暂停计时；点击"确认"立即消失；消失后不进入品牌徽章。
- **规则与边界**：所有来源共享同一 DOM 节点（复用节点、替换文案、重置计时），不叠出多条；文案表达的是"瞬时事件"，不做常驻状态；与待办条不同，警示条不参与数量体系。
- **依据**：`permissions.js::showGlobalWarningBanner`（`maybeShowGlobalFullAccessNotice` / `maybeShowEgressDegradedNotice` / `maybeShowEgressPartialNotice` 均收口至此）；`skill-picker.js` 的 MCP 注册失败路径；`app.css` 的 `.permission-global-warning-toast`。

### UC-5L3 警示在上、待办让位
- **触发**：红色警示条与待办条同时可见。
- **预期现象**：警示条固定在顶部（标题栏下沿 0.65rem），待办条自动让位到其下方（+48px），两者保持 8px 间距、互不叠压；警示消失后待办条平滑弹回原位。
- **规则与边界**：堆叠由 `.main-center:has(.permission-global-warning-toast)` 一条规则驱动，不依赖 JS 排序；警示层级高于待办条；弹回动画走 `top` 过渡（0.18s）。
- **依据**：`app.css` 的 `:has()` 堆叠规则、`.human-interaction-banner { transition: top ... }`。

### UC-5L4 「完全访问」控件克制强调
- **触发**：全局权限模式为完全访问（触发器带 `is-global-full-access`）。
- **预期现象**：触发器不再有整块强调（无描边 / 底色 / 光晕），与另外两档同形；风险只通过图标与文字的琥珀色表达；悬停时图标与文字保持琥珀色不被中性化。
- **规则与边界**：`is-global-full-access` 类保留供 JS 同步状态，但不再承载任何样式；浅色主题下使用深琥珀（`#b45309`）保证对比度；"完全访问开启"的事件提示由 UC-5L2 的红色警示条承担。
- **依据**：`app.css`（原 `.composer-permission-trigger.is-global-full-access` 规则移除，留注释说明）；`permissions.js::renderPermissionMode` 的 `trigger.classList.toggle('is-global-full-access', ...)`。

### UC-5L5 三档盾牌图标家族
- **触发**：查看权限触发器（随模式切换）或下拉菜单中的三档图标。
- **预期现象**：三档为同一盾牌家族——盾（请求批准）、盾 + 勾（替我审批）、盾 + 警示（完全访问）；完全访问盾牌内的感叹号方向标准（竖线在上、圆点在下），圆点与竖线同宽，15px 真实尺寸下清晰可辨。
- **规则与边界**：触发器图标由 `PERMISSION_MODE_ICONS` 注入，菜单图标需 `shell-body.html` 与 `frontend/index.html` 双份同步；圆点必须 `stroke="none"`（否则继承父级 1.8 描边被撑到 3.8 单位）。
- **依据**：`permissions.js::PERMISSION_MODE_ICONS`；两份 HTML 中 `.permission-mode-ico` 的完全访问选项。

## 3. 视觉规格速查

| 部件 | 尺寸 | 描边 | 颜色语义 | 动效 |
|---|---|---|---|---|
| 待办条（展开） | 高 40px · 宽 min(560px, 100%−2rem) | 内环 1px 琥珀 34% | 琥珀 = 常驻待办 | 6s 自动收起；悬停/聚焦暂停；`top` 让位 0.18s |
| 铃铛徽章（收起） | 19×19 圆形，钉在品牌图标右上角 | 1px floating 描边 | 琥珀 + 未读点 | 点击切换展开态 |
| 红色警示条 | 高 40px · 同宽 | 内环 1px 红色 42% | 红色 = 瞬时事件 | 9s 自动消失；悬停/聚焦暂停；确认即关闭 |
| 权限触发器 | 高 30px（几何未变） | 默认描边不变 | 仅图标/文字按档着色 | 完全访问不再有整块强调 |
