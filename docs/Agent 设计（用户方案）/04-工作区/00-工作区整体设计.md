## 1. 一句话定位

"机器的桌面"：虚拟路径模型、越界授权、回收站、上传/浏览/媒体——所有文件进出的公共地基。

## 2. 目标 / 非目标

**目标**
1. 一个心智模型：工具的 `/` = 会话工作根，未指定会话目录时取默认 `WORK_DIR`；越界需授权且一次授权、会话内复用；
2. 删除永远可回收（.trash），敏感区受保护；
3. 上传/浏览/预览覆盖日常素材流转。

**非目标**
- 不做版本控制（那属于用户的 Git/改动审查插件）；不做云同步。

## 4. 跨功能不变式

1. **先解析后执行**：一切文件操作先过 `safe_work_path` 类解析与越界检查；Shell 相对路径按**生效工作目录**（`workdir`）解析，保证判定基准与执行基准一致（见 01/UC-4A5）。
2. **可回收承诺**：删除类操作默认进入 `.trash`（物理删除基本不发生）。
3. **会话记忆**：授权目录、可见性规则都以会话为单元，不跨会话泄漏。
4. **图片引用持久**：图片通过统一准入固化为内容寻址对象；消息与队列只保存引用，规范对象只能按可达性回收。
5. **执行根一致**：会话创建时可指定工作目录；工具执行、安全策略与审计使用同一会话工作根。目录校验、默认目录与子代理优先级见 [01 · UC-4A7](01-路径模型与安全解析方案设计-UseCase清单.md)。
6. **选择结果明确**：Windows 原生选择器以 `GetResult()` 取得用户确认结果；取消保持原选择。前端显示目录、创建参数与会话保存目录一致，见 [06 · UC-4F4~4F5](06-打开协议与路径选择器方案设计-UseCase清单.md) 与 [05/06 · UC-5F11~5F13](../05-WebUI对话界面/06-会话档案与技能面板方案设计-UseCase清单.md)。
