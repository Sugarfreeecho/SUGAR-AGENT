## 1. 功能定位

"出界怎么办"的完整闭环：弹卡 → 授权 → 记忆 → 复用。

## 2. UseCase

### UC-4B1 越界触发审批
- **触发**：受限模式下写类工具访问工作区外绝对路径。
- **预期现象**：审批卡片弹出（含路径与操作说明）；批准后操作**立即执行**；拒绝则明确报错（工具结果为"用户未批准"）。
- **依据**：`add_authorized_dir` 调用链、审批卡片（../07-权限审批/05）。

### UC-4B2 授权记忆与复用
- **触发**：同会话再次访问已批准目录。
- **预期现象**：不再弹卡，直接放行；授权列表可在会话元数据中查（`authorized_dirs`）。
- **规则与边界**：授权以**目录**为粒度（文件级授权自动上收为目录）；默认回退 = [WORK_DIR]；重复授权自动去重（Windows 大小写不敏感归一）。
- **依据**：`get_authorized_dirs_for_session / is_path_authorized_for_session / _is_path_authorized`。

### UC-4B3 所需目录计算
- **触发**：一次操作涉及多个越界路径。
- **预期现象**：系统计算出**最小包裹目录集合**（合并同父目录），一次弹卡覆盖多路径（而不是逐个弹）。
- **依据**：`compute_required_authorization_dirs`。

### UC-4B4 会话初始化
- **触发**：新会话创建（或旧会话无授权记录）。
- **预期现象**：自动初始化 `authorized_dirs=[WORK_DIR]`；无法解析的旧数据被安全兜底。
- **依据**：`ensure_session_authorized_dirs`、`agent_harness.py` L5278/5894/6214。

## 3. 边界

- 完全访问模式下不弹卡（见 ../07-权限审批/12），但路径安全解析仍然执行。
- 授权不跨会话共享（安全默认）。
