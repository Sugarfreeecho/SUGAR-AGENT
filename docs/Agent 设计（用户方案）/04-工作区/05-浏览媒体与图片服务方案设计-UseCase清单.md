## 1. 功能定位

工作区的"浏览器"：文件/目录列表、可见性、图片元数据与媒体响应。

## 2. UseCase

### UC-4E1 目录浏览
- **触发**：打开工作区面板 / 进入子目录。
- **预期现象**：列表含名称、体积、行数（文本）；条目数有上限（超多文件截断并提示）；归档/二进制有类型标记。
- **依据**：`_list_workspace_dir / _workspace_file_item / _workspace_dir_item`。

### UC-4E2 可见性规则
- **触发**：工作区含内部目录（如 `.trash`、会话内部结构）。
- **预期现象**：内部目录按规则隐藏或过滤（用户看不到噪音）；不以"消失 bug"形式出现（规则稳定）。
- **依据**：`_is_workspace_visible_dir`、`_resolve_workspace_rel_dir`。

### UC-4E3 图片元数据
- **触发**：浏览目录含图片。
- **预期现象**：图片返回尺寸等元数据（带缓存，不重复解析）；SVG 尺寸有像素解析回退；坏图不阻塞列表。
- **依据**：`_workspace_image_metadata_item / _cached_workspace_image_dimensions / _svg_image_dimensions`。

### UC-4E4 媒体响应
- **触发**：在界面查看图片/媒体。
- **预期现象**：图片正常加载（含缓存头）；大图首屏可用；越界路径不可通过媒体接口读取（仅工作区内）。
- **依据**：`_workspace_media_response / workspace_media / workspace_image`。

### UC-4E5 搜索与定位
- **触发**：按名称查找工作区文件。
- **预期现象**：扫描有范围/数量上限；结果可直达打开。
- **依据**：`_scan_workspace_files`。

## 3. 边界

- 浏览视图**不**提供写操作；写走工具与上传（04）。
- 会话目录内部细节不在浏览面（属 ../08）。
