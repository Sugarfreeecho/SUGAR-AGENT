## 1. 功能定位

工作区的"浏览器"：文件/目录列表、可见性、图片元数据与媒体响应。

## 2. UseCase

### UC-4E1 目录浏览
- **触发**：打开工作区面板 / 进入子目录。
- **预期现象**：列表含名称、体积、行数（文本）；条目数有上限（超多文件截断并提示）；归档/二进制有类型标记。
- **依据**：`_list_workspace_dir / _workspace_file_item / _workspace_dir_item`。

### UC-4E2 可见性规则
- **触发**：工作区含内部目录（如 `.trash`、会话内部结构）。
- **预期现象**：内部目录按规则隐藏或过滤（用户看不到噪音）；不以"消失 bug"形式出现（规则稳定）。
- **依据**：`_is_workspace_visible_dir`、`_resolve_workspace_rel_dir`。

### UC-4E3 图片元数据
- **触发**：浏览目录含图片。
- **预期现象**：图片返回尺寸等元数据（带缓存，不重复解析）；SVG 尺寸有像素解析回退；坏图不阻塞列表。
- **依据**：`_workspace_image_metadata_item / _cached_workspace_image_dimensions / _svg_image_dimensions`。

### UC-4E4 媒体响应
- **触发**：在界面查看图片/媒体。
- **预期现象**：图片正常加载（含缓存头）；大图首屏可用；越界路径不可通过媒体接口读取（仅工作区内）。
- **依据**：`_workspace_media_response / workspace_media / workspace_image`。

### UC-4E5 搜索与定位
- **触发**：按名称查找工作区文件。
- **预期现象**：扫描有范围/数量上限；结果可直达打开。
- **依据**：`_scan_workspace_files`。

### UC-4E6 会话身份（会话目录/草稿）的浏览与媒体解析
- **触发**：文件树、文件选择器、打开/定位、文本、图片尺寸、图片/音视频与 HTML 预览请求携带 `session_id` 或草稿身份。
- **预期现象**：按该会话**有效根**（见 01/UC-4A8）解析相对路径；HTML 资源 URL 携带会话身份并绑定实际文件根，兄弟资源（CSS/图片）请求保持目录身份；文件树刷新/切换会话忽略过期响应；媒体缓存按实际绝对路径区分同名文件；历史图片从会话根读取、子代理相对附件按父会话根读取。
- **规则与边界**：未携带会话身份时保持既有缺省（与调用方给定的根一致）；目录被删除时保留配置身份、接口返回 404，不静默回落默认根；共享存储职责见 04/00。
- **依据**：`webui.py` 浏览/文本/媒体/预览接口；回归 `tests/test_webui_paths.py`、`tests/test_workspace_media_snapshots.py`、`tests/test_image_preview_browser.py`。

## 3. 边界
