## 1. 一句话定位

Agent 的"成长系统"：插件、技能、MCP、Hooks 四条扩展线——全可热更新、全可审计、全有信任门槛。

## 2. 目标 / 非目标

**目标**
1. 四条扩展线均"装上即用、改完即新"（无需重启，最多滞后一次请求）；
2. 扩展产出的工具/命令/UI 进统一管控（注册表/插槽/审计）；
3. 未信任扩展不生效（fail-closed）。

**非目标**
- 不做插件市场/远程分发（安装是本地行为）；插件代码的沙箱化程度以宿主边界为准。

## 4. 跨功能不变式

1. **签名驱动**：一切"是否变化"用签名判定（配置签名/树签名/注册表签名），不靠轮询。
2. **可用性=已信任+已启用+加载成功**：三者缺一，扩展的外部表现即为"不存在"。
3. **失败局部化**：单扩展故障不拖垮主进程与其它扩展。
