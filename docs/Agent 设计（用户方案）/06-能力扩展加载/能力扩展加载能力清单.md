## 8. 边界说明
- 插件携带的"工具"最终经宿主工具注册桥进入工具系统（见工具系统清单）。
- Skills 正文与资源的注入流程属于 ReAct 运行时（见 ReAct 清单 §2）。
- MCP 图片的对象存储、协议投影和请求预算由 [识图与多模态投影](../09-横切能力/02-识图与多模态投影方案设计-UseCase清单.md) 统一定义。
