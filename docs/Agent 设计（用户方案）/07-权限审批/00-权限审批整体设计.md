## 1. 一句话定位

Agent 的"刹车与方向盘"：三档权限模式 + 工具能力分类 + 授权引擎 + 审批闸口 + 人工问答 + 出口守卫。

## 2. 目标 / 非目标

**目标**
1. 危险操作前必须有人（或配置好的复核）拍板；
2. 拍板结果可记忆（规则/授权目录），减少重复打扰；
3. 一切决策可审计、可解释（为什么放行/为什么拦截）。

**非目标**
- 不做操作系统级沙箱（以应用层策略+审批为主）；
- "完全访问"仍保留危险识别与自保护底线（见 ../03-工具系统/02）。

## 4. 跨功能不变式

1. **默认安全**：未明确允许 = 按模式处理（请求批准/替我审批），绝不"默认放行"。
2. **记忆有界**：规则/授权/记忆（grants）按会话作用、可清理。
3. **失败保守**：复核失败/超时 → 倾向不放行（转人工或拒绝）。
4. **强制项跨模式**：非删除类高危命令、以及按生效工作目录解析后仍越界的删除，在完全访问下仍走红框单次授权；工作区内删除为普通审批（见 02 UC-7B3）。
