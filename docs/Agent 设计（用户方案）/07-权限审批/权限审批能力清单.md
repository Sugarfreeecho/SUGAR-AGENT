# 权限审批 · 能力清单（代码证据版）

> 对象：MyAgent 权限审批与安全决策体系（security/ 包 + 审批闸口 + 人工交互）
> 代码版本：HEAD `6acc6bf` + API 识图工作区改动（2026-09-14 扫描；含 9-14 路径基准修复）
> 图例：【图】见 `approval.architecture.html`（11 节点）；【卡】图中卡片；【单】仅本清单

## 1. 权限模式与预设
| 能力 | 位置 | 状态 |
|---|---|---|
| 三档模式：请求批准（ask_for_approval）/ 替我审批（auto_review）/ 完全访问（full_access） | `security/models.py` `PermissionMode` | 【图】 |
| 全局默认 + 会话覆盖；全局模式保留恢复（preserved） | `security/store.py`、`security/runtime.py` | 【卡】 |
| 模式 → 策略预设（PERMISSION_PRESETS → PermissionContext） | `security/runtime.permission_context_for_mode` | 【图】 |
| 开关：SECURITY_ENABLED=0 强制完全访问并隐藏前端选择 | `webui.py` config docs、`security_enabled` | 【卡】 |
| 模式变更即时广播（permission_mode_changed 事件） | `webui.set_session_permissions` | 【单】 |

## 11. 边界说明
- 工作区路径授权细节见"工作区"清单；工具注册表的权限字段见"工具系统"清单。
- 前端权限 UI（三档选择、审批卡片渲染）见"WebUI"清单。
- 附件与独立识图端点使用远程设备身份、read/write/admin scope、附件 grant 和请求 owner 隔离；这套 API 访问控制不等同于工具执行审批，完整契约见 [识图与多模态投影](../09-横切能力/02-识图与多模态投影方案设计-UseCase清单.md)。
