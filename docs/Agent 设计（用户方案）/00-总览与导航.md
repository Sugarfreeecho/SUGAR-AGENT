## 4. 审查工作流建议

1. 从任一模块整体设计进入，先读「功能地图」建立预期；
2. 逐份功能设计按 UC 编号核对现象；🟡/⚪ 条目跳过或按标注预期；
3. 反馈格式：`模块 / UC 编号 / 实际现象（或疑问）`；
4. 修订后各文档在「版本记录」追加，编号保持稳定不断裂。
