## 1. 一句话定位

Agent 的"账本"：**events.jsonl 唯一真源** + 投影/快照/迁移/修复——历史可回放、状态可重建、损坏不静默。

## 2. 目标 / 非目标

**目标**
1. 一切状态都能由事件重建（回放一致性）；
2. 并发写有明确语义（Busy/损坏错误显式化）；
3. v1→v2 迁移可校验、可回退；长日志可安全压缩。

**非目标**
- 不做分布式/多机同步；旧版文件（如 llm_history.json）不承诺作为权威来源。

## 4. 跨功能不变式

1. **真源唯一**：任何派生数据（投影/快照/镜像）可丢弃重建，events 不可伪造。
2. **顺序即事实**：seq 是全系统时间线（UI/告警/审批共用）。
3. **显式失败**：损坏/并发冲突绝不静默吞掉（修得回来就修，修不了就报）。
4. **引用为真源**：会话事件持久化耐久附件身份，不保存一次性请求图片或长期 base64；旧图片只在仓库边界完成准入后迁移。
