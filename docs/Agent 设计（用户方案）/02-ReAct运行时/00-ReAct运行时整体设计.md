## 1. 一句话定位

Ag​​ent 的**执行内核**：决策（模型）→ 行动（工具）→ 观察（结果）循环，串起提示装配、插话、钩子、错误恢复、持久化与观测。

## 2. 目标 / 非目标

**目标**
1. 每轮输入可解释：系统提示、key_context、历史消息如何拼装全部有据可查；
2. 运行可干预：插话（Steer）/中断/恢复全程有安全点；
3. 失败可恢复：错误分类 + 超限压缩 + 断网等待；
4. 状态可回放：与 Runtime V2 的提交边界清晰（写栅栏）。
5. 长运行可收敛：证据充分后停止广泛探索，同时不以硬截断破坏未完成工具调用。

**非目标**
- 不实现"自动重排模型候选"（属 LLM 接入模块）；不做跨会话记忆共享。

## 4. 跨功能不变式

1. **每次只前进一个动作**：模型请求/工具调用串行推进（并行只发生在"只读工具"层面，属工具系统）。
2. **可中断承诺**：所有等待点（模型流、工具、审批、压缩）都可被插话/停止打断。
3. **会话锁**：压缩与请求构建互斥（context policy 锁）；并发策略运行有串行化保护。
4. **先准入再运行**：用户图片在占用运行位前固化为耐久引用；每个模型候选从 Core 历史独立生成 wire 投影。
5. **前缀缓存优先**：临时运行提醒放在请求尾部，不在长历史之前插入动态段；新增历史按前缀增量处理。
6. **run 身份精确**：中断、看门狗、写栅栏与终态收敛均以 `(session_id, run_id)` 为边界；旧 run 的控制信号不得作用于替代 run。
7. **自动续跑有界**：Goal continuation 同时最多一个租约；interrupted 计入退避与连续失败，达到阈值自动暂停。
8. **稳态热路径不回源**：token 前缀、工作流 registry 与 Todo 活跃状态复用受控缓存；初始化、变更、压缩和显式失效边界必须回到权威状态刷新。
