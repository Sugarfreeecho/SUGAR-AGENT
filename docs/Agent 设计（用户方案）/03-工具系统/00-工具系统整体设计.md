- 版本：2026-09-20 v3（覆盖至：当前工作区）

## 1. 一句话定位

模型"手脚"的统一入口：注册表 → 裁决 → 执行器（文件 / Shell / Web / 会话任务）→ 结果与安全处理。

## 2. 目标 / 非目标

**目标**
1. 工具来源可扩（内置/宿主/插件/MCP）而模型侧无感；
2. 每个工具的行为特征（只读、可并行、可中断）机器可读；
3. 危险操作"三层护栏"：危险模式识别 + Agent 自保护 + 审批闸口；
4. 结果进入上下文前做截断/脱敏/转存。
5. 大目录检索的成本有界：默认尊重 ignore、达到结果上限即停；目录发现不隐式读取全部文件。
6. 被压缩的会话细节可通过稳定引用按当前/全局作用域检索，不要求把全量历史重新塞回活跃上下文。

**非目标**
- 不做工具级的计费统计；策略细节（审批模式）归 ../07-权限审批。

## 4. 跨功能不变式

1. **单一来源**：所有工具经同一注册表进入模型视野（无"野生工具"）。
2. **裁决先行**：一切执行先过执行策略/审批（UC-302/303 链路）。
3. **结果可信**：结果状态（成功/失败/等待）以真实落盘与真实执行结局为准。
4. **路径可恢复**：跨工具复用完整路径；拼写失败可提示候选但不得静默改写目标。
5. **历史检索最小范围**：`history_context` 默认只查当前会话；仅在用户明确要求跨会话时使用全局作用域，且所有操作保持只读、有界返回。
