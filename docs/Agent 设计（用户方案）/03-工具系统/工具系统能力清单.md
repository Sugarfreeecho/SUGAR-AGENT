## 4. 文件系统工具
| 能力 | 位置 | 状态 |
|---|---|---|
| read_file：范围读取、超长行"虚拟化"、不可读文本嗅探；行数缓存按 mtime/size 失效 | `read_file`、`_virtualize_text_lines`、`_read_file_sniff_unreadable_text` | 【图】 |

## 8. 边界说明
- 权限审批策略细节（allow/ask/deny、审批卡片）归"权限审批"模块清单；技能/插件/MCP 注册细节归"能力扩展加载"模块清单。
- Shell 执行器在 Windows 上以 PowerShell（本机）为主路径；POSIX 环境使用 Bash，逻辑对称保留。
