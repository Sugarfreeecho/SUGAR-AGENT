## 1. 功能定位

"删得安全、结果进得干净"：软删除护栏 + 结果脱敏/截断/转存。

## 2. UseCase

### UC-3F1 软删除到 .trash
- **触发**：`delete_file`。
- **预期现象**：目标（文件或目录）被移动到 `WORK_DIR/.trash/`，命名带时间戳前缀；回执给出回收路径；可人工回收。
- **规则与边界**：这是**非物理删除**（可恢复）；`.trash` 本身与 `sessions/`、`skills/` 及其子路径**拒绝删除**。
- **依据**：`delete_file / TRASH_DIR / _delete_path_prohibited_reason`。

### UC-3F2 容量护栏
- **触发**：删除大对象（合计超 `TRASH_SIZE_WARN_MB`，默认 500MB）。
- **预期现象**：**整体拒绝**（不部分移动），提示手动清理或调大上限；无任何文件被移动。
- **依据**：`delete_file` 体积检查段。

### UC-3F3 敏感内容脱敏
- **触发**：工具参数/结果/日志中出现敏感资源（密钥文件路径、口令样式文本）。
- **预期现象**：输出中对应片段被打码（统一脱敏函数）；界面与日志一致；不影响真实执行。
- **依据**：`redact_sensitive_tool_text / redact_sensitive_tool_obj / _sensitive_tool_resource_error`。

### UC-3F4 结果截断与大结果转存
- **触发**：工具结果超长。
- **预期现象**：按策略截断（保留头尾或前段，策略可配置）；更大结果自动转存临时文件并给引用路径（模型可按需再读）。
- **规则与边界**：截断长度可由环境变量调整（`_tool_result_truncate_keep_chars_from_env`）；转存文件走临时生命周期。
- **依据**：`_truncate_output / _save_result_to_tempfile / _cleanup_temporary_write_files`。

### UC-3F5 只读结果的虚拟行包裹
- **触发**：只读类工具输出超宽行。
- **预期现象**：按可读宽度做"虚拟换行"渲染（不改变真实内容与后续读取语义）。
- **依据**：`_wrap_read_only_tool_output_lines`。
