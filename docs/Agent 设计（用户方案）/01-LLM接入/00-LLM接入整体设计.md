## 1. 一句话定位

以 **LLM Provider API 为中心**的统一接入层：三类线协议（Responses / Chat Completions 兼容 / Anthropic Messages）自动判别，调用、重试、对冲、预算、切换、降级、观测一体化。

## 2. 目标 / 非目标

**目标**
1. 任意 OpenAI 兼容 / 官方 OpenAI / 官方 Anthropic 端点皆可接入，`auto` 规则保守可解释；
2. 调用具备工程级韧性：重试、首 token 对冲、共享预算、时限与并发上限；
3. 模型可自动（候选链）或手动切换，切换/降级路径全部有状态提示；
4. 多模态（识图）在**不支持**时优雅降级而不是报错。
5. 独立识图服务复用同一 model profile、三协议 transport、图片预算和流关闭语义，不复制第四套供应商客户端。

**非目标 / 待实现**
- `LLM-HEDGE`（对冲提示）、`LLM-BUDGET`（预算将尽告警）为规范项 🟡（见 ../09-横切能力/）；
- 不做跨供应商的"价格最优自动选型"（人工档案排序为准）。

## 4. 跨功能不变式（全模块共同承诺）

1. **协议透明**：上层（ReAct/工具）永远不感知线协议差异；协议判定只发生在接入层。
2. **预算共享**：对冲、重试、切换共享同一逻辑请求预算（见 03），任何路径不绕过上限。
3. **尽力真实**：切换/降级/重连全程产生状态提示；失败不"假装成功"（见 04/07）。
4. **隐私保守**：Server 端存储开关、密钥脱敏（见 08）默认安全。
5. **图片历史不变**：每个候选从耐久附件引用按自己的能力和预算重新投影；wire 层省略不反写 Core 历史。
