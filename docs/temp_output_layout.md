# TempOutput 运行产物

本机制管理的临时文件与大工具结果统一分配到全局默认 `WORK_DIR/TempOutput`，不随会话项目目录、子代理工作目录或 Git worktree 切换。已有会话、配置、日志、`.trash` 与 `.tool_results` 不迁移、不删除。

## 目录与所有者

- `scratch/<sessionId>/<runId>-<随机后缀>/` 保存一次性脚本及中间文件。运行时按执行上下文分配目录，以持久标记记录宿主进程和仍使用目录的子进程身份。
- `tool-results/<sessionId>/<toolCallId>/result.txt` 保存完整工具结果。结果不进入临时文件清理列表，正常完成、取消、重启和 scratch 回收都不删除它，以保留历史及分叉会话中的路径引用。
- 路径片段编码、私有目录、独占创建与包含性检查避免路径穿越和覆盖非本次分配的文件。结果调用标识缺省时使用随机标识。

## 工具与生命周期

`write_file(temporary=true)` 将名称映射到当前运行的 scratch，并返回实际绝对路径；它不会覆盖调用参数所指向的项目文件。普通写入和用户文件软删除保持原语义。长 `python -c` 的自动入口脚本同样在 scratch 创建。

`run_shell` 保留项目 cwd，将子进程 `TEMP`、`TMP`、`TMPDIR` 指向当前 scratch。执行服务取得 scratch 租约，后台任务或提升后的任务仍可使用目录；运行结束只标记可回收，最后一个使用进程完成后才删除。完成、取消与异常均释放运行所有权，失败清理保留标记供下次启动重试。

启动回收仅检查 scratch 中框架创建的有效标记。运行尚未结束且宿主仍存活，或登记的子进程仍存活时保留；已结束且无活跃子进程，或宿主与子进程身份均失效时才能删除。尚未完成进程身份登记的租约无法证明已空闲，保守保留。符号链接、重解析目录和没有有效标记的陌生内容不被递归清理。

当前运行已分配的 scratch 作为该运行的临时授权目录，不因自定义会话项目而额外触发工作区外路径处理；动态代码、网络和危险操作仍按原权限策略判断。共享 TempOutput 根、其他会话及其他运行目录不获得额外授权。

通用原子文本写入使用唯一同目录 staging 文件，替换失败或取消时清理本次 staging。搜索、文件选择和变更审查默认排除 `TempOutput`；显式文件读取仍可访问工具返回的完整路径。普通 Shell 自行向项目写入的文件不根据名称猜测删除。

## 验收

1. 默认会话、自定义项目和子代理的内部产物均进入同一个全局 TempOutput，项目同名文件不被覆盖。
2. 超长工具结果在终稿和重启后保持可读，且不进入 `.trash`。
3. 临时写入和自动 Python 脚本进入 scratch；成功、失败、取消均回收，后台进程存活期间保留。
4. 启动回收跳过活跃进程、符号链接及陌生目录；通过创建时间区分 PID 重用，删除确认失效的框架目录。
5. 原子替换故障不留下 staging、不覆盖原文件；默认搜索与变更审查不展示运行产物。
