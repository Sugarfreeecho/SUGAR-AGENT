# 2026-09-27 新会话后台预取

## 行为

- 点击“新会话”时在后台创建隐藏草稿；首条用户消息提交后，草稿转为普通会话并进入列表。
- 同一标签页重复点击或刷新页面会复用待用草稿。待用 ID 存在 `sessionStorage`，避免两个标签页把独立消息发送到同一个预取会话；旧版本 `localStorage` 记录会在读取时迁移。
- 预取失败时，首次发送仍可按原路径即时创建会话。用户选择保留未发送的草稿，不做自动清理。

## 可靠性与性能

- 新建会话先创建根目录，避免新 UUID 首次落盘触发子代理目录全树扫描。
- 隐藏草稿创建不使 `/sessions/state` 缓存失效；首条用户消息提交并转正时再通知列表更新。
- 启动时若发现草稿已经有持久化的首条用户消息，会修复元数据并恢复到会话列表，覆盖事件提交与草稿转正之间的进程退出窗口。

## 验证

- 前后端测试覆盖预取响应、隐藏与转正、Runtime V1/V2 重建恢复、同页预取复用、刷新复用、旧记录迁移和预取失败回退。
- 执行 `npm run build`，并以 `PYTHONUTF8=1` 运行 `scripts/check_frontend_dist_sync.py` 校验生成产物。
