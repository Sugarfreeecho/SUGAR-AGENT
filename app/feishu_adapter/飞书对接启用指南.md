# SugarAgent 飞书对接启用指南

本指南用于启用 SugarAgent 的飞书机器人长连接能力。完成后，可以直接在飞书手机端或桌面端与 SugarAgent 对话。

该功能使用飞书企业自建应用和 WebSocket 长连接：

- 不需要公网 IP 或公网回调地址。
- 不要求启用 Remote Control。
- SugarAgent 主动连接飞书开放平台。
- 当前版本支持文本、群聊 @、会话绑定、停止运行和文字审批命令。

## 一、安装飞书官方 SDK

在仓库根目录打开 PowerShell，执行：

```powershell
.\python\python.exe -m pip install lark-oapi
```

也可以安装项目的全部依赖：

```powershell
.\python\python.exe -m pip install -r app\requirements.txt
```

检查是否安装成功：

```powershell
.\python\python.exe -c "import lark_oapi; print('lark-oapi installed')"
```

## 二、创建飞书企业自建应用

1. 打开飞书开放平台：<https://open.feishu.cn/app>
2. 登录后选择“创建企业自建应用”。
3. 填写应用名称，例如 `SugarAgent`。
4. 进入应用详情页，在“应用能力”中添加并启用“机器人”。

注意：需要使用企业自建应用机器人，不能使用只能发送消息的群自定义 Webhook 机器人。

## 三、申请机器人权限

进入应用的“权限管理”，搜索并开通以下应用身份权限：

| 权限标识 | 用途 | 是否必需 |
|---|---|---:|
| `im:message.p2p_msg:readonly` | 接收用户发给机器人的单聊消息 | 单聊必需 |
| `im:message.group_at_msg:readonly` | 接收群聊中 @ 机器人的消息 | 群聊必需 |
| `im:message:send_as_bot` | 以机器人身份回复消息 | 必需 |

如果暂时只使用单聊，可以先不申请群聊消息权限。

## 四、配置长连接事件

1. 进入“事件与回调”。
2. 事件接收方式选择“使用长连接接收事件”。
3. 点击“添加事件”。
4. 添加应用身份事件：

```text
im.message.receive_v1
```

5. 保存配置。

这里不需要填写 Request URL，也不需要把本机端口暴露到公网。

## 五、获取应用凭证

进入“凭证与基础信息”，复制：

- App ID，通常以 `cli_` 开头。
- App Secret。

App Secret 属于敏感凭证，不要提交到 Git、发送到群聊或写进截图。

## 六、配置 SugarAgent

打开：

```text
app\.env
```

如果文件不存在，可以从 `app\.env.example` 复制一份；如果已经存在，请直接编辑，不要覆盖原有模型和运行配置。

在文件末尾加入：

```dotenv
FEISHU_ENABLED=1
FEISHU_APP_ID=cli_你的AppID
FEISHU_APP_SECRET=你的AppSecret

# 首次测试时可以暂时留空；正式使用建议配置。
FEISHU_ALLOWED_OPEN_IDS=
FEISHU_ALLOWED_CHAT_IDS=

# 群聊必须 @ 机器人，建议保持开启。
FEISHU_GROUP_REQUIRE_MENTION=1

# chat：一个单聊/群聊对应一个 SugarAgent 会话。
# thread：飞书话题存在 thread_id 时，每个话题对应一个会话。
FEISHU_SESSION_SCOPE=chat
```

开关说明：

```dotenv
FEISHU_ENABLED=1  # 启用
FEISHU_ENABLED=0  # 禁用
```

修改配置后必须重启 SugarAgent。

## 七、发布飞书应用

1. 进入“版本管理与发布”。
2. 创建应用版本。
3. 设置应用可用范围，至少包含需要使用机器人的账号。
4. 提交并发布。
5. 如果企业启用了管理员审核，等待管理员批准。

应用没有发布、用户不在可用范围内时，即使长连接成功也可能收不到消息。

## 八、启动并验证连接

在仓库根目录启动：

```powershell
.\RUN.bat
```

启动日志中应能看到类似内容：

```text
Feishu transport adapter started
connected to wss://...
```

如果缺少 `FEISHU_APP_ID`、`FEISHU_APP_SECRET` 或 `lark-oapi`，启用状态下启动会明确报错。

## 九、第一次对话

### 单聊

在飞书中找到应用机器人，发送：

```text
/help
```

或直接发送普通问题。首次普通消息会自动创建并绑定 SugarAgent 会话。

### 群聊

1. 把机器人添加到群聊。
2. 在群里 @ 机器人。
3. 发送 `/help` 或普通问题。

例如：

```text
@SugarAgent 请分析当前仓库的测试失败
```

机器人先回复“已收到，正在处理”，Agent 完成后再回复最终结果。

## 十、配置 allowlist

默认 allowlist 为空时，所有处于应用可用范围、且机器人能够接收到消息的用户或群都可以使用它。正式使用建议限制身份。

### 获取用户和群 ID

在可信单聊中发送：

```text
/whoami
```

群聊中发送：

```text
@SugarAgent /whoami
```

机器人会返回：

```text
sender_open_id: ou_xxxxxxxxx
sender_union_id: on_xxxxxxxxx
chat_id: oc_xxxxxxxxx
```

把允许的 ID 写入 `app\.env`：

```dotenv
FEISHU_ALLOWED_OPEN_IDS=ou_user1,ou_user2
FEISHU_ALLOWED_CHAT_IDS=oc_group1,oc_group2
```

多个值使用英文逗号分隔。保存后重启 SugarAgent。

## 十一、支持的命令

| 命令 | 作用 |
|---|---|
| `/help` | 显示帮助 |
| `/new [名称]` | 新建并绑定 SugarAgent 会话 |
| `/session` | 查看当前绑定的会话 ID |
| `/whoami` | 查看用户和群聊 ID |
| `/stop` | 停止当前会话运行 |
| `/approve <审批ID>` | 允许等待中的工具调用 |
| `/reject <审批ID>` | 拒绝等待中的工具调用 |

同时支持中文命令：`帮助`、`新会话`、`会话`、`停止`。

当会话正在运行时，再发送普通消息会作为 append steer 排队，不会同时启动第二个冲突运行。

## 十二、常见问题

### 1. 启动时报 `No module named lark_oapi`

执行：

```powershell
.\python\python.exe -m pip install lark-oapi
```

### 2. 启动正常，但机器人收不到单聊消息

检查：

- 应用是否已经发布。
- 当前用户是否在应用可用范围内。
- 是否申请了 `im:message.p2p_msg:readonly`。
- 是否订阅了 `im.message.receive_v1`。
- 事件接收方式是否选择长连接。

### 3. 单聊可以使用，群聊没有反应

检查：

- 机器人是否已经加入群聊。
- 消息中是否 @ 机器人。
- 是否申请了 `im:message.group_at_msg:readonly`。
- `FEISHU_ALLOWED_CHAT_IDS` 是否包含当前群的 `chat_id`。

### 4. 能收到消息，但不能回复

确认已申请：

```text
im:message:send_as_bot
```

### 5. 提示用户或群聊不允许

检查：

- `FEISHU_ALLOWED_OPEN_IDS`
- `FEISHU_ALLOWED_CHAT_IDS`

ID 必须使用英文逗号分隔，修改后需要重启。

### 6. 机器人一直回复“正在处理”但没有最终结果

检查 SugarAgent 日志中的模型、工具或 Runtime 错误。飞书只是消息入口，实际运行仍由 SugarAgent 的会话控制服务完成。

### 7. 如何完全关闭飞书功能

修改 `app\.env`：

```dotenv
FEISHU_ENABLED=0
```

然后重启。关闭后不会导入飞书 SDK、建立长连接或创建飞书状态目录。

## 十三、当前版本边界

当前第一版主要完成文本对话闭环，暂未提供：

- 图片、文件和语音输入输出
- 交互式审批卡片按钮
- 编辑同一条飞书消息实现逐字流式输出
- 飞书侧会话选择器和设备管理界面

更详细的技术配置参见 [`docs/feishu.md`](docs/feishu.md)。
