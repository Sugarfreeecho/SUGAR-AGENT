## 三点五、飞书 Web 内部接口结论（2026-11-19 18:01 修正）

`/web/common` 只是安全组件外壳。真正的发送是 `POST internal-api-lark-api.feishu.cn/im/gateway/`，
protobuf + `x-command: 5`，需要浏览器 Cookie 与数字 chatId（`oc_` 不行）。

实测：18:00 小Sugar、18:01 王影（跨租户）均 `200` 且消息可查。

结论：**web API 通道可行**；顺序为 官方 API → Web API → DOM（最终兜底）。

## 四、设计要求（此前漏记，现补）

### 受客户端限制、标记为不实现的组合

| 组合 | 原因 |
| --- | --- |
| user-cli 发表情包 | 用户身份拿不到 sticker 的 file_key |
| web 发贴纸 | 前端只能发文本表情码（实测 `22:32 text "[大哭][大哭]"`） |
| user / web 发卡片 | 输入区没有卡片编辑器入口；user 模式按设计降级文字 |
| web API 发附件 | 上传走 Service Worker，页面层无法复现 |
