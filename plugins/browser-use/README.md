# 浏览器连接（browser-use）

SugarAgent 浏览器扩展的内置宿主适配器。网页自动化继续使用固定版本 Playwright MCP 的 20 个操作与观察工具，另外提供只读 `browser_get_context`，查询活动页、本轮绑定页及选区。

0.4.0 侧栏发送时默认自动关联活动网页的稳定标识、标题、URL 和选区，正文仍由 Agent 按需通过 `browser_snapshot`／`browser_find` 读取。页面引用随统一会话输入持久保存，排队期间切换标签不会改写已接受输入；原生标签切换也不会改变运行中的任务目标。Agent 显式调用 `browser_tabs` 选择或新建页面时，可改变自己的目标。绑定页被关闭后要求重新选择，不回退到其他页面。

主程序 Agent 没有侧栏消息引用时，首次调用 `browser_get_context` 获取并绑定活动页。内部选择使用稳定 Chrome target ID 对应 Playwright 页面，同网址的不同标签也分别处理；自动观察不会把目标页抢到前台。选区、标题和网页内容均作为外部数据处理。

- `host.py`：同源设置、限定能力的配对、设备撤销、模型列表、附件入口、带页面引用的消息准入与实时会话订阅。0.5.0 增加会话用量读取、全局权限模式选择，以及只限工作区／实际会话附件的文件读取。权限写入复用主程序服务；受范围限制的凭据不可修改全局权限，完全访问要求显式确认。
- `human.py`：认证的人机交互列表、提问回答／取消、完整审批决策和提问图片读取；复用主程序持久化与执行恢复。
- `page_context.py`：有界页面引用验证与外部数据格式化，不读取整页正文。
- `runtime.py`：受管理的 Node 子进程、工具目录、可信会话身份、权限复核、运行结束清理。
- `node/`：Playwright MCP 连接及官方 v2 扩展桥接协议。只监听随机 loopback 端口，扩展来源和随机令牌同时校验。
- `web/`：主程序中的浏览器连接设置页。

桌面安装包已携带独立 Node 与锁定版生产依赖，在设置中启用后即可配对。源码开发环境先在 `node/` 执行 `npm ci`。安装版组件缺失时提示修复或重新安装应用，不执行全局 npm 安装，也不依赖系统 PATH。插件不下载或启动另一份日常浏览器。

扩展安装及使用见仓库 `browser-extension/README.md`。浏览器输出保存在用户 SugarAgent 状态目录的 `browser-use/outputs/`，不写入插件源码目录。

首次添加后端接口需要重启后端；此后按现有插件热重载机制重新发现。禁用插件会结束其子进程、移除可调用状态和事件监听器；已接受的普通聊天仍归统一会话服务所有。
