出站会话与任务

选择发起任务的 SugarAgent 会话与外部会话。操作交由该会话的 Agent 执行，沿用现有审批。

选择“新建会话”会使用新上下文；选择已有 ID 会续接该会话，失败时不会自动改成新建。释放连接保留历史，断开后续接需要目标支持 resume。

中间进度以提示消息回送，不唤醒模型；结束回报包含已收集的全部普通回复文本，并在来源会话排队触发后续处理。同步调用直接返回，不重复回送。ACP v1 不保证标记哪段文本是最终回复：文本流显示为进度，任务结束后形成结果。

外部 Agent · 出站

      
配置 SugarAgent 可以委派任务的目标。空对象表示尚未配置出站目标。

    

      

      
      
      
对象的 key 为目标 ID。字段：command、args、env_refs、permission（reject/allow）、timeout（秒）、session_control（可选）。凭据通过环境变量名引用。

      

        
        

      
配置示例
{
  "dsh": {
    "command": "node",
    "args": ["/absolute/path/to/dsh.js", "--profile", "acp"],
    "env_refs": ["DEEPSEEK_API_KEY"],
    "permission": "reject",
    "timeout": 600
  }
}
请将示例路径替换为实际安装的 DSH 入口。保存配置不会启动外部 Agent。
