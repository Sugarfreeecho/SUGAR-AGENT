# 面向用户：功能介绍

可以这样介绍：“这个插件让当前登录的B站账号按任务找视频、分析内容、记日报，也能根据设置处理私聊、@和评论回复；Agent通过MCP使用B站业务工具。”随后按用户关心的场景展开。

| 功能 | 当前能力 |
|---|---|
| 多任务值班 | 多组关键词、各自谷时窗口/每日额度/间隔/预算/会话/日报；共享全局视频判重，原生事实记账生成归档 |
| 视频分析 | 搜索、详情、字幕、评论、弹幕；可选宿主ASR或本地Whisper转写 |
| 内容投递 | 按设置公开评论、@指定名字、向固定UID私信；评论可使用合法表情码或库中的图片 |
| 入站私聊 | 对方UID复用会话、处理中继续接收新消息、逐条完整回复；超过500字本轮不投递 |
| 入站评论和@ | 独立开关覆盖未刷过的视频；同一视频同一楼层复用会话，目标由宿主锁定 |
| 白名单 | 白名单可用全部已启用B站业务能力；陌生人只聊天，不给工具；始终不开放本机命令和文件 |
| 收藏 | 显式工具收藏指定视频，或值班选片后按全局收藏夹配置自动收藏；可查询收藏夹，不支持新建/取消收藏 |
| 表情库 | 查B站合法表情码、保存评论表情图、打标签、按关键词检索；控制台可管理 |
| 多账号 | 保存多个账号的登录态，选择一个运行；可取消扫码/登出/切换/删除本地保存账号 |
| 独立提示词 | 值班、私聊、评论回复各自完整系统提示词，可编辑、持久保存和恢复默认 |
| 持久队列 | 游标、任务和发送回执持久保存；首次不回历史，未知发送结果保留待核对，避免盲目重发 |
| MCP与Skill | 14个业务工具以MCP注册；随包Skill覆盖管理、自检、工具使用、用户设置和功能介绍 |

不要承诺多个账号同时在线运行；当前是多份保存、单个运行。不要把控制台存在或源码更新当成在线服务已加载新版。工具可见也不代表自动任务或自动回复已开启。

与DSH原版的完整比较见插件根目录 `UC_COMPARISON.md`。目前仍未直接迁移旧版的延迟90秒自动评论复核、7天评论巡检限制、旧安装更新/打开目录UI；已提供手动评论可见性工具和新的持久入站队列。AGENTS.md人设目录设置尚未接入完整系统提示词；使用提示词编辑器。回答迁移范围时应说明这些区别。
